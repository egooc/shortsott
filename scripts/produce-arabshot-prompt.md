## 1. 소재 고르기
```
node scripts/reddit-scout.js --period week --limit 10

```

### ★소재는 «욕구»에 걸려야 한다 (사례 71 — 여기서 가장 자주 실패한다)
솜씨 구경은 예쁘지만 끌어당기지 않는다. 도마뱀이 달걀 먹고 모래를 깎는 편이 그래서 심심했다.
**아래 축 중 하나에 명확히 걸리지 않으면 그 소재는 버려라.**

| 축 | 레퍼런스 근거 | 안전하게 가는 법 |
|---|---|---|
| 고통·신체 | 클라이머 연고 200만 · 코 푸는 법 38만 | 상처·수술 장면 금지. 해결·요령 쪽으로 |
| 먹기·경쟁 | 식탐 친구 66만 · 오만 치킨 12만 | 먹방 아닌 «뺏김·양·속도»의 긴장 |
| 공포·긴장 | 환공포증 집 46만 | 유혈·시신 금지. 시각적 불편함까지만 |
| 돈·격차 | 두바이 부자 6.5만 | 비난 아닌 구경 |
| 사회적 마찰 | 답정너 34만 · 핸드폰 잔소리 29만 | 특정인 조롱·싸움 금지 |
| 낯선 곳의 일상 | 인도 담배 28만 · 일본 관광 20만 | 국가·민족 비하 금지 |
| 규모·불가능 | 나무집vs벽돌집 190만 | — |

**유튜브 정책 안에서 간다(소유주 지시 2026-09-21).** 유혈·부상·시신, 싸움·괴롭힘, 성적 내용,
따라 할 위험이 있는 행동, 정치·종교·젠더 논쟁은 **소재 단계에서 뺀다.** 조회수가 나와도 광고가 안 붙고
신고를 부른다. **자극은 소재가 아니라 프레임에서 만든다** — 아래 6번을 보라.

챌린지·뻔한 공감·AI 생성물은 레퍼런스 바닥권이다. 고르지 마라.
- 받기: `node scripts/reddit-scout.js --fetch <permalink>`

## 2. 원본 손질
- **번인 글자를 반드시 확인한다.** 앞뒤에 제목 카드나 영어 자막이 흔하다. 0.1초 단위로 사라지는 시각을 재라
  (사례 61: 24.0초부터 깨끗해 보였지만 24.6초까지 흐릿하게 남아 첫 프레임에 잔상이 찍혔다).
- **화면 안에서 위치가 움직이는 번인 오버레이는 그 소재를 버려라.** 가릴 방법이 없다(사례 67의 달걀 압축 실험).
- 여러 구간을 이어 붙일 때는 **반드시 재인코딩**한다. `-c copy` 로 만든 concat 은 타임스탬프가 어긋나
  엔진의 정밀 디코드가 프레임을 잃고 `Source ended before requested clip frames` 로 반려된다(사례 67).
  ```
  ffmpeg -f concat -safe 0 -i cc.txt -c:v libx264 -crf 18 -preset medium -c:a aac -b:a 128k -ar 48000 -movflags +faststart volcano_src.mp4
  ```
- 1080x1920 · 30fps 로 맞춘다. 원본 소리는 **살린다**(어랍숏의 알맹이다).

## 3. 자막 파일
- 원본과 같은 basename 으로 `volcano_src.vtt` 를 둔다. 그러면 ASR 을 부르지 않는다 — **실비 0원**(사례 60).
- 큐는 **공백 포함 11자 이하**. 넘으면 폭 때문에 `Long caption requires matching measured word timing` 으로 반려된다.

## 3.5 제목 — 자극은 여기서 만든다 (사례 71)
레퍼런스 실측: **상위 20편 중 10편이 아래 틀을 쓰고, 하위 15편은 2편뿐이다.**
안전한 소재라도 제목이 밋밋하면 안 눌린다. 반대로 **틀만 제대로 쓰면 평범한 소재도 긴장이 생긴다.**

| 틀 | 레퍼런스 | 쓰는 법 |
|---|---|---|
| **전언형** `~라는 / ~한다는` | 클라이머들이 **쓴다는** 개발바닥 연고(200만) · 담배도 집에서 **만든다는** 인도(28만) | 내부자만 아는 것처럼 |
| **대결형** `A vs B, 어느 게` | 나무집 **vs** 벽돌집, **어느 게 더 좋을까**(190만) | 답을 마지막에 |
| **질문형** `~까` | 모래로 어디**까**지 만들 수 있을**까** | 마지막 장면이 답해야 한다 |
| **극단 부정** `절대 ~못 / ~없는` | 환공포증 환자는 **절대 살 수 없는** 집(46만) | 누가 못 견디는지 지목 |
| **이유 약속** `~한 이유` | 흑인이 N단어를 독점하게 **된 이유**(89만) | 이유를 실제로 보여줘야 한다 |
| **과장 규범** `이 정도는` | 남자가 코 풀 때 **이 정도는 해야지**(38만) | 과장인 게 보이게 |

두 줄 모두 짧게. 같은 글자 크기라 긴 줄 하나만 줄일 수 없다.
★**약속한 것을 마지막 장면이 반드시 보여줘야 한다.** 못 보여줄 약속은 낚시다 — 정책 위반이고 이탈을 부른다.

## 4. 원고 (여기가 어랍숏의 전부다 — 사례 68·77)

### 4-1. 길이와 꼴
레퍼런스 @urabshorts 실측: **한 문장 평균 31.7자.** 토막을 쓰면 어랍숏이 안 된다.
- **대상을 이름으로 부르고 시작한다** — "갯가재라는 생물은 사냥을 할 때면".
- **연결어로 문장을 겹친다** — "이처럼", "제아무리 ~해도", "심지어".
- **끝에 화자의 평을 붙인다** — "이 정도면 거의 깡패나 다름없네요".
- 한 문장이 카드 여러 장에 걸쳐 흐른다. 카드 하나 = 문장 하나가 아니다.
- 카드는 공백 포함 11자 이하로 쪼갠다(`BMDOHYEON 107pt` 기준).

### 4-2. ★말맛 — 대상을 «캐릭터»로 다뤄라 (사례 77, 소유주 지시 2026-09-21)
길이만 맞추면 «설명문 9줄»이 된다. 소유주 지적: "소재는 흥미로운데 말맛을 더 살릴 순 없나."
레퍼런스를 다시 뜯어보니 차이는 길이가 아니라 **화자의 태도**였다.

| 장치 | 레퍼런스 | 쓰는 법 |
|---|---|---|
| **의인화** | "웬만한 것들은 **그의** 상대가 안 되는데요" | 사물도 «놈»으로 부른다. 돌변한다·부아를 낸다·덩치를 불린다 |
| **비유** | "치고 빠지는 게 완전 **복서 스타일**이고" | 일상 사물·직업에 빗댄다. 한 편에 하나면 충분 |
| **딴지·감탄** | "**살려주시옵소서**", "오 마이갓" | 화면 자막(D컷)이 이 역할을 한다 — "선을 넘네", "누가 좀 말려" |
| **끝 한마디** | "이 정도면 거의 **깡패나 다름없네요**" | 제목과 호응시켜 닫는다 |

**자가 점검**: 아홉 문장에서 «~합니다/~있습니다»로만 끝나고 주어가 전부 사물이면 말맛이 없는 것이다.
고쳐 쓴 예(arab17→arab21) —
- 전: "검고 매끈하던 표면이 점점 잿빛으로 일어나는데요"
- 후: "검고 매끈하던 게 슬슬 잿빛으로 **부아를 내는데요**"

★**원고를 고치려면 새 작업 폴더에서 다시 시작해야 한다.** 이미 음성을 산 폴더에서 원고를 바꾸면
`paid_request_uncertain` 으로 막힌다(설계된 안전장치다). 소스·자막 파일만 복사해 새 폴더를 판다.

### 4-3. ★긴장 설계 — 7축은 «극단으로» 끌고 간다 (소유주 지시 2026-09-22)

> "긴박하지 않아도 긴박하게, 위험하지 않아도 위험한 것처럼, 놀랍지 않아도 놀라운 것처럼
> 원고를 만들어 주고 상황을 끌고 가고 묘사해 줘야 재밌어지는 것이다."

소재를 고르는 7축(§1)은 **후보를 거르는 체**일 뿐이다. 그 축을 **화면에서 끌어내는 건 원고**다.
비버가 길을 건너는 건 그냥 길 건너는 것이다. 그걸 «대치»로 만드는 건 문장이다.

| 장치 | 안 쓴 문장 | 쓴 문장 |
|---|---|---|
| **판돈 선언** 무엇이 걸렸는지 먼저 말한다 | "비버가 차선을 건넙니다" | "**1톤짜리 픽업 앞에서** 비버가 차선을 건넙니다" |
| **가정법 최악** 안 일어난 일을 상상시킨다 | "트럭이 멈췄습니다" | "**한 발만 늦었어도** 하는 순간이었는데요" |
| **시간 압박** 초를 센다 | "천천히 끌고 갑니다" | "**그 사이에도** 뒤에서는 계속 기다리고 있는데요" |
| **단위 과장** 크기를 견준다 | "긴 나뭇가지" | "**제 몸통 두 배는 되는** 나뭇가지" |
| **보류** 결정적인 걸 미룬다 | (바로 설명) | "**문제는 여기서부터인데요**" |
| **반문** 시청자를 끌어들인다 | "대단합니다" | "**이걸 보고도** 경적을 울릴 수 있을까요" |
| **서열 선언** 누가 이겼는지 못박는다 | "무사히 건넜습니다" | "**결국 이긴 쪽은** 비버였습니다" |

**사다리로 쌓는다.** 아홉 문장이 평평하면 안 된다. 뒤 문장은 앞 문장보다 한 단계 세야 한다 —
상황 → 판돈 → 압박 → 최악의 가정 → 반전 → 판정.

★**거짓말은 하지 마라. 긴장은 «프레임»으로 만든다.**
- 되는 것: **가정법**("~할 뻔했는데요", "~였다면"), **비교**("~두 배"), **판정**("이긴 쪽은"),
  **반문**, **보류**. 전부 화면에 있는 것만 가지고 만든다.
- 안 되는 것: 화면에 없는 사건을 단정하는 것("차가 들이받을 뻔했습니다" — 실제로 안 그랬다면 거짓이다),
  없는 숫자를 지어내는 것, 없는 소리를 있다고 하는 것.
- 판별법: **그 문장이 틀렸다고 지적당했을 때 화면을 가리키며 방어할 수 있는가.**
  가정법은 방어된다("그랬다면"이라고 했으니까). 단정은 방어되지 않는다.

## 5. 편집표 — 끊기는 자리를 만들지 마라 (소유주 지시 2026-09-20)
- **현장음만 나오는 빈 구간을 두지 않는다.** 내레이션을 등끼리 붙이고 그 사이에 **1초(30프레임)짜리 화면 자막 컷**만 끼운다.
- 목표 밀도: **0.7초마다 글자가 바뀐다.** 35초 기준 내레이션 카드 40장 안팎 · 화면 자막 5장 · 리액션 5개.
- ★**0번 프레임에서 시작하지 마라.** 정밀 디코드가 한 장을 잃는다(사례 67). 첫 컷은 f15 쯤에서 시작한다.
- ★**컷은 전부 이어 붙인다.** 같은 샷 안에서 시간이 건너뛰면 `same_shot_source_gap` 으로 반려된다.
  1차 제출 → 실측 프레임을 받아 → 그 길이로 이어 붙여 재제출. 이 왕복은 정상이다.
- 리액션 문구는 `position: [540, 1060]`. 자막이 y=1250 이라 그 위로 190px 띄워야 겹치지 않는다(사례 60).
- 효과음은 pop·bonk·ding 중 **실제 동작이 있는 자리에만**. 수를 맞추려고 채우지 마라.

## 6. 자막은 화면에 있는 것만 말한다 (가장 자주 틀리는 곳)
- 자막·내레이션을 쓰기 전에 **그 시각의 프레임을 직접 뽑아 봐라.**
- 원본 제목을 근거로 쓰지 마라. "Octopus Getaway" 를 믿고 '도망간다'고 썼는데 문어는 그냥 헤엄쳤다(사례 62).
- **크롭 밖은 없는 것이다.** 사람 다리가 원본엔 있어도 잘려 나가면 '사람이 올라탄다'고 쓸 수 없다.
- 번인 카운터처럼 화면이 이미 숫자를 말하고 있으면 **우리 자막은 숫자를 또 쓰지 않는다.** 반응을 쓴다.

## 7. 돌리기
```
python tools/vol_edit.py submit <wd> <wd>/edit.json
python tools/vol_edit.py cam <wd> <wd>/cam.json     # 세로 원본이면 전 샷 cx=0.5
python tools/vol_edit.py preview <wd>
```

- 완료 판정은 `.volcano_drive_state.json` 의 `status: done` + `step: rinbox_finish`.

## 8. 현장음 깔기 (엔진이 못 하는 일)
```
python tools/mix_ambient.py <wd> <final.mp4> <wd>/final_tight.mp4 --gain -6
```
엔진은 내레이션 구간에서 TTS 만 내보내고 원본 소리를 버린다. 이 도구가 **N 구간에만** 원본 소리를 깔아
전 구간 현장음을 만든다. D 구간은 이미 원음이 있으므로 건드리지 않는다 — 안 그러면 두 번 겹쳐 들린다.
