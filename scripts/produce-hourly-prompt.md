4. **후처리.** `python tools/reframe_midform.py <final.mp4> <edit_dir> <ko|ja> <out.mp4>` — 미드폼 밴드 + BGM + 라우드니스.
   제목은 기본 `--title-style mystery` 로 굽는다 (1줄 회백 + 2줄 선홍·큰 글씨·두꺼운 외곽선).
   ★**0초부터 두 줄이 다 떠 있어야 한다.** 쇼츠는 첫 프레임이 곧 썸네일이라 페이드인·시차를 주면
   피드에서 «제목 없는 그림»으로 지나간다 (소유주 지시 2026-09-22). 2줄에만 0.2초 박동을 준다 —
   가려지는 순간 없이 시선만 끈다. 되돌리려면 `--title-style classic`(흰줄/노란줄).
4.5 **후킹 하이라이트 — 반드시 한다** (소유주 승인 2026-09-22: "슬로우 좋은데? 자연스러워졌어 이대로 생산에 반영")
```
python tools/hook_prepend.py <workdir> <reframe한.mp4> <hooked.mp4>
```
   - 완성본에서 **사건이 고조되는** 2~3초를 잘라 맨 앞에 붙인다. 자막은 그대로 따라온다 — 그래야 알아듣는다.
   - 자를 자리는 `editorial.beats` 의 `escalation`(없으면 reversal) 안에서 **의문문 자막**을 찾아 그 위에 얹는다.
     질문은 답을 기다리게 만든다. ★`payoff` 는 쓰지 않는다 — 결말 대사가 미리 노출된다.
   - **맺음은 «슬로우»로 만든다.** 질문이 끝난 뒤 여운 구간(기본 1.0초)을 0.55배속으로 늘린다.
     ★정지 프레임은 쓰지 마라 — 얼리면 끊긴 것처럼 보인다(소유주 지적 2026-09-22).
     느려진 목소리는 어색하므로 그 구간 소리는 내린다.
   - 자를 줄은 **뒤에 여백이 있는 것**을 우선한다. 원본이 이미 쉬어 주는 자리를 잡으면
     여운이 억지스럽지 않다. 질문 뒤에 바로 답이 붙는 자리는 피한다 — 답이 새면 궁금할 이유가 없다.
   - 이음새는 꼬리 페이드아웃 + 머리 페이드인(0.35초)으로 BGM 이 툭 끊기지 않게 하고, 끝에 라우드니스를 다시 맞춘다.
   - 손잡이: `--slow 0.55`(속도) · `--tail 1.0`(여운 길이) · `--at <초>`(지점 직접 지정) · `--seconds`(길이).
   - **발행 패키지는 이 결과물로 만든다.** 후킹을 안 붙인 mp4 로 패키지를 만들지 마라.

   - 이게 끝이다. **승인도 발행도 하지 마라.**
