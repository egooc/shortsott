# 쟁점 브리핑 10/15 편 — 쟁점 자료 모으기 지침

★ 10/14 소유주 결정: 채널은 이제 **정부·여당(민주당) 지지 시청층**을 노린다. 중립 아님.
해설은 정부·여당 시각에서 국민의힘·윤석열 전 정부를 비판한다. 다만 **사실은 사실대로** — 없는 사실·확정 안 된 의혹을 사실처럼 쓰지 않는다(명예훼손·허위정보 정책).
조롱·비꼼은 해설과 인용에서 써도 되지만, 사람에 대한 사실 주장은 출처가 있어야 한다.


## 인용 원칙 (바뀜)
- 균형 규칙 폐지. 인용은 **여당·정부 쪽 발언 60~70%**(시원한 반박·질타 장면), **국민의힘 쪽 발언 30~40%**(해설이 반박할 대상 — 원문 그대로, 잘라서 왜곡하지 않는다).
- 국힘 발언도 앞뒤를 잘라 뜻을 뒤집지 않는다. 한 문장 끝까지.
- 진보 스피커 방송(매불쇼, 김어준의 겸손은힘들다 뉴스공장, 박시영TV 등 시사 유튜브·라디오)의 논평 구간도 인용 후보. **한 구간 15~50초 발췌만**, 통째 사용 금지, 출처 표기 필수.
- "센 한마디"는 지지층이 통쾌해할 말 위주로 표시.

## 할 일 (쟁점 하나당)
1. 사실 조사: 웹 검색으로 무엇이 쟁점인지, 일지(날짜별), 양쪽 주장, 확인된 사실과 다투는 부분, 앞으로 볼 대목.
   모든 사실에 출처(언론사·날짜·URL)를 붙인다. 확인 안 된 건 "주장"으로 적는다.
2. 발언 영상 찾기: 유튜브에서 양쪽 인물이 직접 말하는 영상(국감 질의, 기자회견, 대변인 브리핑, 방송사 뉴스 클립).
   검색: `yt-dlp "ytsearch15:검색어" --flat-playlist --print "%(id)s|%(title)s|%(channel)s|%(duration)s|%(upload_date)s"`
   방송사·국회·정당 공식 채널 우선. 영상 길이 15분 이하 위주(전체 토론 통째 사용 금지).
3. 받기 (D:/midform/politics-hour/episodes/20261015/src/ 에, 이미 있으면 건너뛰기):
   `yt-dlp -f "bv*[height<=1080][vcodec^=avc1]+ba[ext=m4a]/bv*[height<=1080][ext=mp4]+ba[ext=m4a]/b[height<=1080]" --merge-output-format mp4 -o "D:/midform/politics-hour/episodes/20261015/src/%(id)s.%(ext)s" -- <id>`
   소리가 있는지 확인(ffmpeg volumedetect, mean_volume > -40dB).
4. 받아쓰기 (Speechmatics, 유료이니 필요한 영상만):
   `python D:/midform/scripts/rinbox_transcribe.py <mp4> D:/midform/politics-hour/episodes/20261015/transcripts/<id>.json --lang ko`
   결과는 낱말 단위 [[start,end,text],...]. 로컬 whisper 금지.
5. 인용 후보 고르기: 발언자가 화면에 보이며 직접 말하는 구간. 한 구간 15~50초, 문장 처음에서 시작해 문장 끝+0.3초에서 끝낸다.
   **기자 내레이션·앵커 멘트 구간은 인용으로 쓰지 않는다**(발언자 본인 목소리만). 화면에 얼굴이 나오는지 ffmpeg 로 한 장 떠서 눈으로 확인.
   쟁점당 인용 합계 6~9분 목표(위 비율).
   인용마다 "센 한마디"(썸네일·자막 강조용, 원문 그대로)를 1~2개 표시.
6. 해설 화면 배경용 구간(b-roll): 자막·사람 얼굴 클로즈업이 덜한 회의장·전경 구간 시각 몇 개.

## 지킬 것
- 출처 표기(영상: 채널 날짜)는 반드시 남긴다. 로고 숨기려고 지우지 않는다.
- summary·facts_confirmed 는 사실만(출처 붙여서). 관점은 sides·notes 에 '여당 쪽 논리'로 정리해 둔다(해설은 메인 세션이 쓴다).
- 개인 범죄 의혹은 "의혹/주장"으로만, 확정처럼 쓰지 않는다.
- 볼케이노 서버·volcano MCP 쓰지 않는다. 키 값을 출력·기록하지 않는다.
- 한국어 파일은 UTF-8로 저장. PowerShell Set-Content/Out-File 금지.
