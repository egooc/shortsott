- 카테고리(아이돌)는 하되 **소재(그룹·멤버)는 경쟁 약한 곳**. 1황 소재(리센느·프로미스나인 등) 신규 진입 = 만벽.

- 터지면 원인(멤버/그룹/춤/장면) 분석 → 결 맞춰 1일 3편.

## 2. 무대 음원 Content ID · 소속사 신고 위험

| 소스 | 걸리는 것 | 결과 | 대응 |
|---|---|---|---|
| 음악방송 무대(인기가요·뮤뱅·엠카·쇼챔) | 방송사 영상 + 음원 Content ID 이중 | 대개 수익 귀속·지역 차단, 방송사 몰아서 수동 신고 시 스트라이크 | 무대 원음은 길게 쓰지 않는다. claim-probe.js 로 사전 검사, 걸리면 rinbox-strike-plan.js |
| 공식 MV·음원 | 레이블(배급사) Content ID | 수익 귀속 또는 차단 — 스트라이크는 드묾 | 원음 BGM 금지, 현장음은 내레이션 아래로 |
| 소속사 자컨·공식 유튜브(예: JYP 자컨) | 소속사 Content ID(영상) | 대체로 수익 귀속 | 전자책 «저작권도 안 잡는다»는 이쪽 이야기. 짧게·내레이션 위주 |
| 예능(방송사) | 방송사 | SBS 는 IG·FB 막힘(holder_platform_blocks) | ko IG 팬아웃은 비SBS 소스로 |
| 팬 직캠(홈마) | 촬영자 개인 신고 | 스트라이크 직행 가능, 팬덤 반발 | **쓰지 않는다** |
| 소속사 «신고» | 루머·악성 편집·성적 대상화 | 법적 대응(소속사들이 사이버렉카 고소 중) | 칭찬·귀여움·성장 서사만. 열애·불화·탈퇴 루머, 몸 클로즈업 금지 |

- 매칭 ≠ 발행 차단: 예약 해제 신호는 regionRestriction 뿐(메모리 licensed-content…).
- 3스트라이크 유예 7일 — 2스트라이크면 그 권리자 편 전부 내린다(전자책 3장, rinbox-strike-plan.js).
- 소스 URL 은 설명란에 쓰지 않는다(소유주 지시).
