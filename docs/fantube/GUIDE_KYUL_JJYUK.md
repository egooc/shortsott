## 1. 쮸뀨미의 결 — 한 문장

**«아이돌을 관찰 대상처럼 놓고, 직장인·인터넷 밈 어휘로 한 줄 주장을 세운 뒤, 10초 안에 증거 컷으로 증명하고, 팬의 속마음 한마디로 끝낸다.»**

채널명이 «연구실»인 이유가 결 그 자체다. 제목은 관찰 결과 보고서 제목이고, 영상은 증거, 자막은 연구원(팬)의 메모다.

## 3. 화면 규격 (608x1080 업로드 기준 → 1080x1920 환산)

- **띠**: 짙은 회색 (32,32,32), 높이 20~25%(1920 기준 384~480px). 영상은 띠 아래 전체 폭, 9:16 크롭.
- ★**창은 소스가 정한다**(10/29 소유주, 레퍼런스 예능셔틀 «꺼드럭대는 최산 조롱하는 우영» 102만·32초): **박힌 자막이 있는 방송·예능 소스는 정사각 창** — 원본 세로 전체×가로 56%(1080p 기준 폭 1068)를 1080×1092 로 놓고, 위 394 는 제목, 아래는 비움(팬 자막은 거기). 편집은 자르기+«잠시 후» 카드뿐인데 자막이 다 보이니 100만. 9:16 꽉 찬 창(폭 608 = 가로 32%)은 얼굴은 크지만 가운데 자막이 양쪽에서 잘린다 → **직캠·공항·무자막 소스에만**. spec.window='square', 창 폭 1000 미만은 렌더러가 막는다. 아래 10/28 실측은 쮸뀨미·지우해(직캠·무대 위주)에만 해당.

- **제목 1줄**: 띠 안 y 143~178/1080(글자 높이 35px → 1920 기준 약 62px), 흰색, 보통 굵기.
- **제목 2줄**: y 195~239/1080(글자 높이 44px → 약 78px), 연하늘(약 #9DD3FF 계열) 굵게. 1줄과 2줄 사이 17px.

## 4. 편집 문법

- 길이 **9~15초가 본체**(12편 중 8편). 20초 넘는 건 «모음»뿐.
- 구조: **주장(띠) → 증거 컷 2~6개 → 끝 한마디**. 공항 편(컷 0~5)처럼 한 장면이면 자막 종류를 바꿔 가며 리듬을 만든다.
- **교차 증거**: «나 혼자 편한 안무»는 무대 풀캠 ↔ 연습실 영상을 번갈아 붙여 주장을 증명. 한 소스 안에서만 자르지 않는다.
- 첫 컷: 제목의 주인공 얼굴이 이미 보이는 컷(공항 편은 0.8초에 매니저+지우 전신, 바로 상황 자막).
- 끝: 끝 한마디 자막이 뜬 채 1~2초 두고 끊는다. 원음 페이드 없음.
- 소리: 원음 그대로지만 **크게**(평균 −15~−20 dB, 피크 0 dB). 우리 −14 LUFS 규칙([[loudness-minus14-all-lanes]])과 같은 방향.

## 8. 우리 레인 적용 (설윤앓이·제임스 과몰입)

베끼지 않고 결만 가져온다. 틀의 **종류**는 레인마다 다르게([[fantube-lanes-must-look-independent]]).

공통 결:
1. 제목은 **전제/펀치 2줄**. 멤버 이름은 끝에 붙이거나 뺀다. 관계·전환·가정법·원인 규명·«~했을 때» 패턴에서 고른다.
2. 자막 화자는 **팬**: 괄호 반응 + 대괄호 상황 + 따옴표 대사 + 끝 한마디. 해설 TTS 0 유지. 원본 자막은 있으면 두되 기대지 않는다.
3. **9~15초**. 주장 → 증거 2~6컷 → 끝 한마디. 전환 순간은 플래시나 색 강조로 찍는다.
4. 댓글 카드는 끝 한마디가 대신한다 → 카드 0~1장(베댓이 영어뿐인 코르티스 문제 해소). GUIDE_TOP2x12의 «카드 4~6»은 이 가이드로 대체(소유주 확정 뒤).
5. 소리 −14 LUFS 유지.

레인별 차이(페어 방지):
- **설윤앓이**: 띠 없이 **영상 위 상단 그라데이션 어둡게 + 흰 고딕 2줄**(타이포 간판과 같은 결), 자막은 흰 고딕 + 하늘색 강조, 끝 한마디는 «…(앓는 소리)» 식 팬 톤. 관계·«~했을 때»·전환 패턴 중심.
- **제임스 과몰입**: **크림색 띠 + 검정 손글씨 2줄**(스티커 간판과 같은 결), 자막은 둥근 글꼴 + 주황 강조, 끝 한마디는 «과몰입 중…» 식. 미성년 4명 때문에 B(관계 비유)·G(외모 조건) 패턴 금지, 미성년 단독 클로즈업 첫 컷 금지(minor_gate). 능력 의인화·원인 규명·모음 패턴 중심.

적용 순서: ① 소유주 «틀 바꿔» 확정 → ② tpl_b.py 에 자막 층(괄호·대괄호·따옴표·끝 한마디·강조색) + 띠 2줄 크기 비대칭 추가 → ③ 10/30 n08·n01 부터 이 틀 → ④ 11/06 7일 비교에 «결 전환 전/후» 열 추가.

## 9. 권리·안전 체크 (이 결로 갈 때)

- ★10/28 소유주 결정 «공항 기자영상 직캠 써야지. 우리도» → 공항 기자 영상(뉴스엔·디스패치·K-POPIT 등)과 직캠을 소재로 쓴다. 출처 표기 기준([[social-source-rights]] credit_only): 설명란 «출처: <매체/촬영자> <원본 제목>»(링크 금지), spec.rights={basis:'credit_only', source:'…'} 로 편마다 기록. 홈마 직캠은 촬영자 워터마크가 화면에 남으면 그 컷은 피하고(크롭으로 안 잘리면 제외), 언론사 영상 우선. 레퍼런스가 이미 쓴 같은 순간은 피하고 같은 날 다른 각도·다른 순간으로.

- 외모 조건(키·몸)은 미성년 금지, 성인도 비하 아닌 상황 조건으로만.
