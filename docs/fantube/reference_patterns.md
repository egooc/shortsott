## 2. 패턴 목록 (다시 쓸 이름)

1. **반전형 «알고 보니»** — 오해·기대 → 숨은 이유/실제. «1초만에 놀림에서 걱정으로»(겨울옷=감기), «아일릿 신발»(=무릎 보호), «해원이 폭염에도 껴입은 이유»(=문화 존중), «사자성어 실력»(못할 줄 → 다 맞힘), «이상한 스펙»(=칭찬). 가장 많고 상위권.
2. **한 장면 하이라이트 + 펀치라인** — 예능·자컨 돌발행동/리액션 하나를 잘라 마지막 한 대사로 닫기. «대기업만 하고 싶어», «얘 무슨 대장내시경 하냐고»(제목 비유 회수).
3. **내레이션 썰 «~했다고»** — 퇴근후아이돌 5/5: 편집자 내레이션(TTS 추정)이 사건 전말을 말하고 전언체로 끝. 13~20초.
4. **능력·특성 하나 사례 모음 / 같은 행동 반복** — «오해원의 미친 반응속도»(5개 사례), «인지도 테스트»(A→B 두 번), «원본 → 다른 멤버 재연».
5. **증명형 교차** — 말·관찰 → 그 장면이 증거. «약속 → 이행 몽타주», «무대에서 여유 → 연습 때도», «비하인드 → 공식 결과물», «낚시 → 근거 → 진짜».
6. **디테일 찾기** — 직캠 단체 파트에서 차례로 확인 → 한 명만 다름(«이 분이 문제.. 낼름..?» → «다시 아무일 없는듯..»).
7. **비주얼 + 텍스트 레이어** — 서사는 영상이 아니라 라벨·스펙·댓글 자막이 맡음(«추구미 사복패션», «생얼 출국»). 460만~1,400만.
8. **무대·안무 통째** — 신곡 푸시용, 하위권.
