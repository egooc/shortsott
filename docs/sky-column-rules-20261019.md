## 0. 다섯 줄

1. **100만+ 쇼츠 제목 100개의 공통점은 셋**: 결과를 숨긴다 / 보는 사람을 지목한다 / 카톡 말투. 앞 10자에 핵심 낱말, 전체 15자 안팎, 설명형·해시태그 도배·최상급 남발 금지, 영상이 제목의 약속을 지킬 것.
2. **썰형·쇼핑 대본은 6단**: 제목 읊기 → 배경(원래 이미지) → 문제 → 해결에 나선 사건 → 시청자 반박을 미리 던지고 답 → 사회적 증거(품절·극찬·줄). 문장 길이에 리듬(고른 길이 = AI 티), 삽질 구간엔 숫자, 끝은 열린 결말(~일 듯·~됐다고·~아님?).
3. **채널이 꺾이면 소재부터 바꾸지 말고 세 숫자를 본다**: 노출수(유튜브가 채널을 이해하나) → 클릭률(썸네일·제목) → 지속률(첫 3초·리듬). 어디가 깨졌나에 따라 처방이 다르다. 제목 핵심 낱말을 날짜순 표로 적어 잘 될 때와 안 될 때를 비교한다.
4. **숙련도의 저주**: 오래 하면 단골에게만 말하고 전문용어가 제목에 들어가 노출이 마른다. 알고리즘이 미는 대상은 항상 «처음 보는 사람». 월 1회 초기 10편 vs 최근 10편 언어 점검, 7살이 봐도 되는 말.
5. **올리기 전에 «이 영상엔 어떤 댓글이 달릴까»를 그려 본다**(정정하고 싶어질까, 경험담을 풀고 싶어질까, 훈수를 두고 싶어질까, 맞다·아니다로 싸울까). 댓글이 달리고 싶은 영상만 밀면 저점이 올라간다(바이크 채널 1~2만 → 3~4만, 10만 편 재등장).
