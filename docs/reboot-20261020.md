## 2. 종료 전 각 세션이 남길 것 (마감 보고 또는 06:50 보고)

- 재개 명령 한 줄(파일·인자 포함), 멈춘 지점(조각 번호·단계), 멈추면 안 되는 시각대.
- 예약 업로드 목록은 유튜브 서버에 있으므로 영향 없음 — 다만 **업로드 뒤 태그 삽입·조회 점검(views_check)·저조회 비공개(yt-low-views)가 schtasks 인지 세션 루프인지** 적는다. 세션 루프면 재부팅 뒤 다시 걸어야 한다.
- 인계 문서 갱신·커밋(자기 파일만). 관리자는 handoff-manager·shared-tools·규칙 정리본을 커밋.

## 3. 예약 작업(schtasks midform-*)은 재부팅 뒤 자동 복귀

- 윈도우 예약 작업은 재부팅 뒤 다음 시각부터 자동으로 돈다. 재부팅 중 지나간 회차(예: 07:00 정각 작업)는 건너뛴다 — 관리자가 §4에서 지나간 회차를 확인해 수동 1회.
- Claude 세션 안의 cron(CronCreate: 07:40 보고 등)은 세션과 함께 사라진다 → 재등록.
