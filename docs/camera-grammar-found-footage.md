# 카메라 문법 — 남의 소스로 편집할 때의 판단 기준 (2026-10-18 소유주 지시)

소유주: «직촬이 아니다 보니 소스마다 다른 장면 환경에 놓일 수밖에 없다. 그걸 매끄럽게 해결하기 위한 테크닉으로서 어느 정도는 다 알고 작업하는 판단이 있어야 한다.»

원본 가이드 3장(소유주 제공): `docs/reference/camera-guide/01-ratio-and-cut-linking.jpg` · `02-composition-24.jpg` · `03-movement-transition-24.jpg`. 이 문서는 그 가이드를 **우리처럼 촬영하지 않고 기존 영상을 자르고 움직여 쓰는 레인**에 맞게 옮긴 것이다. 가이드의 수치(고정 60%·아이레벨 70% 등)는 실사 20컷 기준 권장치이므로 그대로 쓰지 않고 원칙만 가져온다.

## 1. 우리 상황에서의 기본 원칙 5개

1. **기본은 평이하게, 강조는 전환점에만.** 샷 크기·각도·움직임 중 «센 것»(익스트림 클로즈업·로우/하이 앵글·더치·드리줌·스매시 컷)은 발견·충격·결론 장면에서만 쓴다. 자주 쓰면 강조가 사라진다.
2. **같은 구도를 이어 써도 되는 조건은 «정보나 감정 단계가 바뀔 때».** 같은 크기·같은 정보의 반복은 지루함이고, 클로즈업→클로즈업은 감정 단계(놀람→눈물)가 다를 때만 허용.
3. **컷 순서는 정보 → 행동 → 감정 → 결과.** 쇼츠 아크(상황→충돌→전환→작은 결말)와 같은 뼈대. 장면 설명(와이드) → 행동 관찰(미디엄) → 감정 집중(클로즈업).
4. **움직임은 적을수록 강조가 산다.** 우리가 만드는 움직임(pad+zoompan·카메라 점·모션 그래프)은 «순간 효과»로만. 상시 움직임은 몰입을 깨고 렌더도 느리다(연금 편 실측: 상시 움직임 렌더 약 15배).
5. **매끄러움은 소리와 형태로 만든다.** 소스가 다른 두 장면을 잇는 가장 싼 도구는 J컷·L컷(소리 먼저/소리 남김)과 매치 컷(형태·움직임 방향 일치)이다. 화면 효과(와이프·디졸브)는 그다음.

## 2. 소스가 서로 다른 장면을 매끄럽게 잇는 기법표

| 소스 상황 | 쓰는 기법 | 금지 |
|---|---|---|
| 두 소스의 **화질·색·화면비가 다름** | 공통 테두리 판(inset) 안에 넣어 «같은 틀 속 다른 창»으로 보이게, 샷 크기 계단(와이드→미디엄→클로즈업)을 두 소스에 걸쳐 유지 | 화면비 다른 두 컷을 전체 화면으로 바로 붙이기 |
| 두 장면의 **시간·장소가 다름** | 크로스 디졸브(짧게) 또는 상단 고정 정보 띠(날짜·장소)로 알리고 J컷으로 다음 소리를 먼저 | 설명 없는 점프 컷 |
| **같은 인물이 두 소스에 다른 크기로** 나옴 | 큰 쪽에서 작은 쪽으로 좁혀 들어가게 순서를 잡고(와이드→클로즈업), 반대라면 중간에 인서트(문서·손·소품) 한 컷 | 클로즈업→와이드로 이유 없이 넓히기 |
| **발언을 이어 붙임**(정치·토크쇼 발췌) | L컷: 앞 발언 소리를 0.3~0.5초 남기며 화면만 먼저 바꿈 / 반응 컷(상대 얼굴)으로 사이를 메움 / 질문은 왼쪽·답변은 오른쪽 배치 유지 | 같은 크기 얼굴 두 컷을 소리 공백 없이 붙이기(튐) |
| **원음 → 해설, 해설 → 원음** 전환 | 원음 끝 0.3초 뒤 컷, 해설 그림은 앞 컷 끝에 걸치게(J컷) | 원음 중간 끊기, 단어 끝 전 컷 |
| **긴장을 올려야** 함 | 고정 → 트래킹(또는 느린 줌 인) → 인서트 → 정지(프리즈) | 빠른 컷 연속으로만 긴장 만들기 |
| **중요한 것을 발견**하는 순간 | 미디엄 → 인서트(그 물건·문서 칸) → 클로즈업(반응) → 하이 앵글(결과·무력감) 또는 로우 앵글(권위) | 발견 전에 클로즈업 소진 |
| **권력·힘의 차이** | 로우 앵글(강자) ↔ 하이 앵글(약자) 교대, 중앙 배치 vs 여백 배치 | 둘 다 아이레벨 투샷으로만 |
| **박힌 자막·로고를 피해야** 함 | 샷마다 창 크기·위치를 바꿔(확대했다 풀기) 띠를 화면 밖으로 — 이 움직임도 «발견·전환» 타이밍에 맞춰 넣어 연출처럼 보이게 | 지우기(LaMa) 우선, 의미 없는 흔들림 |
| **장면 전환 자체가 정보**일 때 | 매치 컷(눈→달, 손 동작→다음 장면의 같은 움직임), 와이프는 공간 이동에만 | 모든 전환을 같은 효과로 |

## 3. 레인별 적용

### 쇼츠(린박스 C · 롱투숏 A · 팬튜브 B · 정치 쇼츠)
- 컷 3~4개 안에서 **샷 크기 계단 하나**(넓게→좁게 또는 그 반대 한 번)만 만든다. 두 번 왕복하면 어지럽다.
- 카메라 점은 샷당 하나(엔진 규칙)이고, 그 하나는 **발견·충격·결론 컷**에 둔다. 상황 소개 컷은 고정.
- 끝 컷은 반응 클로즈업 또는 여백 배치(고립) + 닫는 한 줄 + 소리 페이드(롱투숏 실측 규칙과 같음).
- 팬튜브 `camera:"shots"`(확대했다 풀기)는 자막 회피 목적이지만, 확대 타이밍을 **멤버 표정이 바뀌는 순간**에 맞춰 돌리 인처럼 보이게 한다.
- 훅(첫 1~2초)은 클로즈업 또는 인서트. 와이드로 시작하지 않는다(쇼츠 예외: 장소 자체가 훅일 때만).

### 정치 롱폼(ko·JA)
- 발언 이어 붙이기는 **L컷 0.3~0.5초**가 기본, 발언 사이에는 반응 컷·인물 카드·도표 중 하나를 끼운다.
- 질문자 왼쪽·답변자 오른쪽(JA 「핵심 발언」 판) 배치를 소스가 바뀌어도 유지 — 시선 방향이 바뀌면 좌우 반전 대신 중앙 카드로 사이를 둔다.
- 콜드오픈(제목 낱말 장면)은 미디엄 클로즈업 이상으로 당겨 잡고, 이후 본편 첫 컷은 와이드·정보 띠로 내려와 «정보→행동» 순서를 다시 시작한다.
- 하이퍼프레임 오버레이의 당겨 잡기는 발언의 **핵심 낱말이 나오는 순간**에만. 발언 내내 움직이지 않는다.

### 새 롱폼 레인(연금 ja · 해외 실화 ko)
- 연금: 공문서 칸으로 **돌리 인 + 테두리**는 «지금 말하는 칸»에만, 표는 고정, 장 전환은 와이프(왼쪽 열림) 한 종류로 통일. 그래프는 카운트업보다 최종값 먼저.
- 실화: 바디캠·심문 영상은 공통 테두리 판 안에 고정, 진술 단계가 바뀔 때만 레일 하이라이트가 움직인다. 소리 전환은 J컷(다음 발언 소리 먼저), 자백 장면만 프리즈 프레임 허용.
- 두 레인 모두 생성 이미지는 와이드(장소·상황 소개)와 인서트(서류·물건) 자리에, 인물 클로즈업 자리에는 쓰지 않는다(실존 인물 얼굴 생성 금지).

### 쇼핑 쇼츠
- 0~2초 훅 = 인서트 또는 익스트림 클로즈업 — **키우기 편은 문제 장면(물때·옷더미 등), 팔기 편만 제품**(성장 모드 «첫 3초 상품 금지» 규칙이 우선). 그다음 미디엄(사용 장면), 비밀·원리는 인서트, 증거는 고정 비교 컷, CTA는 중앙 배치.
- 원음이 없는 쇼핑 영상의 L컷은 «앞 문장 말끝이 다음 소스 첫 0.3초에 걸치게»로 옮긴다.
- 중국 소스의 정사각형 창은 «같은 틀 속 다른 창» 원칙 그대로.

## 4. 작업 전 체크 6개(가이드의 실전 체크를 우리 말로)
1. 한 장면에 요소 2~3개만(샷 크기·각도·움직임 중).
2. 기본 구도(아이레벨·고정·미디엄) 비중을 높게.
3. 센 앵글·효과는 전환점에만 — 어느 컷이 전환점인지 편집표에 표시.
4. 정보 변화 없는 반복 금지 — 같은 크기·같은 정보 두 컷이 이어지면 하나를 뺀다.
5. 시선 방향·동선 연결 확인 — 소스가 바뀌어도 왼쪽/오른쪽이 뒤집히지 않게.
6. 중요 순간에만 강한 집중(클로즈업·프리즈·슬로모션).

## 5. 적용 방법
- 각 세션은 편집표(컷 목록)에 **컷마다 «샷 크기 / 각도 / 움직임 / 전환» 네 칸**을 적는다. 비어 있으면 «고정·아이레벨·없음·컷»이 기본값.
- 샷 크기 값은 전 레인 공통 약어: `EWS·WS·FS·MS·MCU·CU·ECU` + `INS`(인서트). N100 own_check는 이 라벨(subject_pos.json)로 «같은 크기 연속»을, 프레임 유사도로 «같은 샷 반복»을 **경고**한다(반려 아님, ffmpeg만).
- 검수(눈검사·관문)에서 위 체크 6개 중 3·4·5번은 반려 사유로 쓴다.
- 이 문서는 관리자가 유지한다. 레인별 실측(어떤 기법이 조회에 먹혔는지)은 결 탐지 속성에 «전환 기법»을 추가해 모은다(도구개발 검토).
