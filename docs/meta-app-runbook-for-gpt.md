# 메타 개발자 앱 만들기 — GPT 컴퓨터 사용 작업 지시서 (2026-10-29)

이 문서는 GPT(컴퓨터 사용 에이전트)가 소유주의 PC 화면을 조작해서 메타 개발자 앱을 만드는 순서다. 위에서부터 한 단계씩 진행하고, 단계마다 «확인» 항목이 맞는지 본 뒤에 다음으로 넘어간다. 배경 설명은 docs/meta-direct-app-prep.md 에 있다(읽지 않아도 이 문서만으로 진행할 수 있다).

---

## 0. 목표 (한 줄)

developers.facebook.com 에 «비즈니스» 유형 앱 하나를 만든다. 이 앱에 인스타 계정 3개를 연결한다(페이스북 페이지는 10-30부터 안 함). 앱은 **개발 모드 그대로** 둔다. 토큰 발급 직전에서 멈춘다.

## 1. 절대 하지 않는 것 (하나라도 해당하면 그 자리에서 멈추고 보고)

1. **비밀번호를 입력하지 않는다.** 이미 로그인된 브라우저(크롬, 소유주 프로필)에서만 작업한다. 로그인 화면이 나오면 멈추고 «로그인 필요»로 보고한다.
2. **2단계 인증(문자·인증 앱 코드)이나 전화번호 인증이 나오면 멈춘다.** 소유주가 직접 한다.
3. **새 페이스북·인스타 계정, 새 비즈니스 포트폴리오, 새 페이지를 만들지 않는다.**
4. **결제, 카드 입력, 광고 계정 생성, 유료 플랜은 하지 않는다.**
5. **신분증, 사업자등록증 같은 서류 제출(비즈니스 인증)은 하지 않는다.** 요구하는 화면이 나오면 멈춘다.
6. **«앱 검수 제출(Submit for Review)», «라이브 모드로 전환» 버튼을 누르지 않는다.**
7. **앱 시크릿의 «보기(Show)» 버튼을 누르지 않는다.** 액세스 토큰을 생성하거나 복사하지 않는다. 화면에 토큰이나 시크릿 값이 보이게 되면 즉시 창을 닫고, 그 값을 보고나 대화 어디에도 적지 않는다.
8. 기존 앱이 이미 있으면 **지우거나 고치지 않는다.** 새 앱을 만들고, 기존 앱 이름은 보고에 적는다.
9. 화면 문구가 이 문서와 다르게 생겨서 판단이 어려우면, 추측해서 누르지 말고 화면을 캡처해 멈춘다.

## 2. 준비물 (작업 시작 전에 확인)

| 항목 | 값 |
|---|---|
| 브라우저 | 크롬, 소유주 프로필 (페이스북·인스타에 이미 로그인된 상태) |
| 만들 앱 이름 | `volcano-publish` (이미 쓰이고 있으면 `volcano-publish-2`) |
| 연락 이메일 | 앱 만들기 화면에 미리 채워진 소유주 이메일을 그대로 둔다 (새로 입력하지 않음) |
| 인스타 계정 3개 | `meow_cinema21`, `numaochicinema`, `shorteg006` |
| 페이스북 페이지 | 쇼핑·ja 쪽 페이지 1개 (목록에서 소유주가 관리자로 있는 페이지. 이름을 보고에 적는다) |
| 개인정보처리방침 주소 | 없으면 비워 두고 보고에 «필요»로 적는다 (도구개발이 만든다) |

## 3. 단계별 순서

### 단계 1 — 개발자 계정 확인
1. 크롬에서 `https://developers.facebook.com/apps` 를 연다.
2. 상황별 처리:
   - «내 앱» 목록 화면이 나오면 → 단계 2로 간다.
   - «시작하기 / 개발자로 등록(Get Started)»이 나오면 → 안내대로 진행한다. 전화 인증이 나오면 **멈춘다**(1-2번 규칙).
   - 로그인 화면이 나오면 → **멈춘다**.
- 확인: 주소창이 `developers.facebook.com/apps` 이고 «앱 만들기(Create App)» 버튼이 보인다.

### 단계 2 — 앱 만들기
1. «앱 만들기(Create App)»를 누른다.
2. 앱 이름에 `volcano-publish` 를 넣는다.
3. 사용 사례(Use case) 화면이 나오면 «기타(Other)»를 고른다.
4. 앱 유형 화면이 나오면 **«비즈니스(Business)»** 를 고른다.
5. 비즈니스 포트폴리오를 묻는 칸이 나오면 **«선택 안 함 / 지금은 연결 안 함»** 을 고른다. 새로 만들지 않는다.
6. 비밀번호 재확인 창이 나오면 **멈춘다**.
- 확인: 앱 대시보드가 열리고, 화면 위쪽에 앱 이름과 **«개발 모드(Development)»** 표시가 보인다. 앱 ID 숫자는 보고에 적어도 된다(공개 값이라 괜찮다).

### 단계 3 — 인스타그램 제품 추가 (인스타 로그인 방식)
1. 대시보드에서 «제품 추가(Add product)»를 누르고 **«Instagram»** 의 «설정(Set up)»을 누른다.
2. «인스타그램 로그인으로 API 설정(API setup with Instagram login)»을 고른다. «Facebook 로그인으로 설정»이 아니다.
3. 권한 항목에 아래 두 개가 들어 있는지 본다. 없으면 추가한다.
   - `instagram_business_basic`
   - `instagram_business_content_publish`
   - (있으면 같이) `instagram_business_manage_comments`
4. «계정 추가(Add account)» 또는 «역할 → 인스타그램 테스터 추가»에서 아래 3개를 차례로 추가한다.
   - `meow_cinema21`
   - `numaochicinema`
   - `shorteg006`
5. 각 계정의 «앱 및 웹사이트 허용» 화면이 뜨면 «허용»을 누른다. 인스타 로그인 화면이 뜨면 **멈추고**, 그 계정 이름을 «로그인 필요»로 보고한다.
6. 테스터 초대 수락은 인스타 쪽에서 해야 한다. 웹 인스타(`https://www.instagram.com/accounts/manage_access/`)에서 해당 계정으로 전환할 수 있으면 «테스터 초대(Tester invites)» 탭에서 «수락»을 누른다. 계정 전환에 비밀번호가 필요하면 **멈추고** «수락 대기» 계정 목록을 보고한다.
- 확인: Instagram 제품 화면에서 3계정이 «연결됨 / 수락됨»으로 보인다. 일부만 됐으면 된 것과 안 된 것을 나눠서 보고한다.
- 계정이 «프로페셔널 계정(비즈니스·크리에이터)이 아님» 오류를 내면 그 계정은 건너뛰고 보고한다. 계정 유형 전환은 소유주가 결정한다.

### 단계 4 — 페이스북 페이지 권한 (Facebook 로그인 비즈니스용)
> ★2026-10-30 소유주: 페이스북은 안 한다 → **이 단계는 건너뛴다.** 단계 3 다음 바로 단계 5로 간다.

1. «제품 추가»에서 **«Facebook 로그인(비즈니스용) / Facebook Login for Business»** 의 «설정»을 누른다.
2. 권한(Permissions) 목록에서 아래 세 개를 추가한다.
   - `pages_show_list`
   - `pages_read_engagement`
   - `pages_manage_posts`
3. 각 권한 옆에 «고급 접근 요청(Request advanced access)»이나 «검수 필요»가 보여도 **누르지 않는다**. 표준 접근 그대로 둔다.
- 확인: 세 권한이 목록에 있고 상태가 «표준 접근(Standard access)»이다.

### 단계 5 — 기본 설정
1. 왼쪽 메뉴에서 «앱 설정(App settings) → 기본 설정(Basic)»으로 간다.
2. «개인정보처리방침 URL(Privacy Policy URL)» 칸:
   - 2절 표에 주소가 있으면 넣는다.
   - 없으면 비워 두고 보고에 «필요»로 적는다.
3. «앱 시크릿» 칸의 «보기»는 **누르지 않는다**.
4. 변경 사항이 있으면 «변경 내용 저장(Save changes)»을 누른다.
- 확인: 저장 후 오류 문구가 없다.

### 단계 6 — 여기서 멈춤 (토큰은 소유주가)
- «토큰 생성(Generate token)» 버튼은 **누르지 않는다.**
- 토큰 발급과 저장은 소유주가 직접 1분 동안 한다. 도구개발 세션이 알려 주는 파일 자리에 붙여 넣는다.
- GPT 작업은 여기서 끝난다.

## 4. 끝나면 보고 형식 (이 표를 채워서 소유주에게)

| 항목 | 결과 |
|---|---|
| 앱 이름 / 앱 ID | |
| 앱 모드 | 개발 모드 (맞음/아님) |
| 인스타 연결 | meow_cinema21: 완료/로그인 필요/수락 대기/프로페셔널 아님 · numaochicinema: … · shorteg006: … |
| 인스타 권한 | instagram_business_basic ○/× · instagram_business_content_publish ○/× |
| 페북 페이지 권한 | pages_show_list ○/× · pages_read_engagement ○/× · pages_manage_posts ○/× |
| 선택한 페이지 이름 | |
| 개인정보처리방침 주소 | 넣음 / 필요 |
| 멈춘 지점과 이유 | (없으면 «없음») |
| 기존에 있던 앱 | (있으면 이름만) |

- 보고에 **토큰, 앱 시크릿, 비밀번호, 인증 코드 값은 절대 쓰지 않는다.**

## 5. 그다음 (GPT 몫 아님, 참고)

1. 소유주가 토큰을 생성해서 지정된 파일에 넣는다.
2. 도구개발 세션이 쇼핑 인스타에 1편, 페북 페이지에 1편을 시험 게시한다. 로그인하지 않은 브라우저에서 그 게시물이 보이는지 확인한다.
3. 보이면 개발 모드 그대로 운영한다. 안 보이면 라이브 전환 조건을 소유주에게 다시 묻는다.
