## 0. 9권이 공통으로 말하는 것 (다섯 줄)

1. **1만·10만 벽의 1순위 원인은 중복도**다(01·04·07·09). 편집·재미 탓부터 하지 말 것. 중복도(시청자가 «같은 내용»으로 느낌, 언어별 칸막이)와 일치율(시각 유사도, Content ID)은 다른 것이다.
2. **중복도는 편집 트릭이 아니라 원고·구조로 푼다**(09·04·06). 확대·반전·색조정은 일치율만 깨고 중복도는 못 깬다. 재편집 레인의 성과 병목은 원고다.
3. **결(結)을 찾아 핀셋으로 좁혀 연속 업로드**(04·01·07·09). 날짜순 조회수에서 튀는 편의 공통점(작품·인물·키워드·구성·제목 틀)이 결이다. 우리 «ko는 터진 소재를 민다»·«기승전규진»이 같은 원리인데, 절차·도구가 없다.
4. **소재는 데이터로만 고르고, 영상 먼저 → 구조 ID → 원고**(09·02·06). 우리 «생성 순서 뒤집기(장면이 원고를 쓴다)»와 일치.
5. **모든 행동을 시간 원가로 잰다**(01·02). 시급 5만 원 잣대, 제작시간별 손익 조회수(10분 5만 / 30분 15만 / 1시간 30만 / 3시간 100만), 원가는 수익의 8% 선.
