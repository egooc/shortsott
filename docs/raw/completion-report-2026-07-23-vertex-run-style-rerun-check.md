## 요청하신 체크 기준 판정

### 1) 도입이 역할 호칭 + 짧은 문장인지 / 풀네임 나열이 사라졌는지

판정: **부분 통과 / 미흡**

- 장점:
  - `보안관`, `아들`, `무법자` 같은 역할 호칭이 실제로 들어감
  - 첫 문장은 사건("납치합니다")으로 시작함
- 미흡한 점:
  - `제드 블레이크`, `브릿`이 계속 등장하고, `slot_2` 첫 문장에 이름+역할 정보가 함께 붙어 여전히 길다
  - 문장 길이도 아직 사용자가 원한 "15자 안팎 짧은 문장 위주" 수준까지는 안 내려옴

### 2) 명사 종결이 섞이는 수준인지, 도배는 아닌지

판정: **부분 통과**

- 전반적으로 서술형 종결이 주류이고, 명사형 종결 도배는 아님
- 하지만 현재 결과에서는 명사형 종결이 거의 살아나지 않았고, 원하는 "섞이는 수준"보다는 아직 설명문 비중이 높음

### 3) closing이 2문장 이내 + 미해결 위협 하나로 끝나는지

판정: **형식상 통과 / 문체는 미흡**

- 현재 closing은 정규화 후 2개 caption unit으로 줄었고, 핵심 위협은 `아들은 여전히 적의 손에 있습니다`로 남음
- 다만 최종 문자열에 마침표가 정리되지 않아 두 문장이 자연스럽게 끊기지 않고 한 덩어리처럼 보임
- 또한 앞절이 여전히 화면 설명에 가까워, 사용자가 원하는 더 짧고 날카로운 closing에 비해 길다

### 4) 사실 유지: 채드/제드 정확, 인과 날조 0, caption 1:1

판정: **통과**

- `채드`, `제드`, `챠스카` 표기 유지
- `에드 라이언`, `연인`, `자작극`, `계략`, `꾸몄` 없음
- closing에서도 `제드가 의도적으로 유인했다` 같은 인과 날조는 제거됨
- `caption_kr_dialogue` 1:1 검증은 `compress-apply` 통과로 유지 확인
