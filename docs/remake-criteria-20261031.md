# 재가공 기준표 — 터졌던 영상을 다시 가져오는 쇼츠 (10-31)

대상은 휴식시간(예능 짤, 64편·1.16억)과 케찹츄(동물, 7월 개설·126편·2,645만)이며, 각 상위 12편을 봤습니다. 공개 페이지와 발굴 키만 썼고 로그인은 하지 않았습니다.

**결론: 이 형식의 핵심은 영상이 아니라 «지금 화제인 인물·이야기에 옛 장면을 붙이는 타이밍»과 «같은 틀»입니다. 다만 두 채널 모두 음성 해설이 없어 재사용 판정 위험이 큽니다. 우리는 음성 해설을 더한 판으로만 시험하기를 권합니다.**

## 1. 소재 고르는 법

| 기준 | 근거 |
|---|---|
| **이번 주 화제 인물의 옛 장면을 고른다** | 아이유 드라마 첫 방송 4일 뒤 12년 전 장면 1,115만. 엑소 콘서트 4일 뒤 6년 전 장면 579만. «효리수» 화제 때 17년 전 장면 2편 902만·599만 |
| **이미 터진 장면을 고른다** | 카이 편의 원본 클립은 4,855만 회(2019), 쇼츠 579만. 태연 편은 원본 130만, 쇼츠 220만 |
| **오래된 것도 통한다, «몇 년 전»을 제목에 쓴다** | 간격 1일~16년 8개월이 모두 터짐. «17년 전 효연», «14년 전 유세윤»(314만) |
| **한 장면에 사건 하나, 30초 안** | 상위 24편 중 22편이 37초 이하, 최단 9초 |
| **터진 인물·이야기는 반복한다** | 휴식시간 64편 중 카리나 12편, 효리수 7편. 케찹츄 «가난» 제목 6편 중앙값 53만(채널 전체 3.5만의 15배) |
| **같은 원본을 제목만 바꿔 다시 쓸 수 있다, 결과는 편차가 크다** | 케찹츄 식탐견 원본 4편: 54만→64만→**311만**→52만. 셰퍼드 2편: 405만→84만 |

터지는 편은 소수입니다. 상위 3편이 조회의 절반(휴식시간 46%·케찹츄 51%)이고, 휴식시간은 8~9월 중앙값이 4.5만~6.2만으로 4월(16만)보다 낮습니다.

## 2. 바꿔야 할 최소 요소

| 요소 | 휴식시간 | 케찹츄 | 우리 최소선 |
|---|---|---|---|
| 화면 틀 | 흰 판, 위 로고+계정, 가운데 원본 | 크림색 판, 위 로고+계정, 아래 걷는 강아지 장식 | 채널 고유 틀 필수 |
| 제목 | **유튜브 제목 ≠ 화면 제목** («이거 보면 재용이 형 못 고름» / «울면서 나와달라는 카리나») | 둘이 거의 같음. «가난한 집의~», «~하면 생기는 일» | 궁금증 제목 + 화면 제목은 상황 설명 |
| 해설 | 음성 없음. 아래 자막 1줄이 2~3초마다 바뀌며 장면을 놀림 | 음성 없음. 아래 자막 2줄이 이야기를 만듦 + 괄호 속마음 말풍선 | **음성 해설 추가** + 자막 |
| 편집 | 원본 자막을 살리고 말장난·효과 글자 추가 | 여러 클립을 잇고 다른 개도 모두 «찹츄»로 부름 | 원본 순서 재구성 + 고유 호칭 |
| 첫 1초 | 얼굴 크게(12편 중 5편) 또는 사건 직전 | 첫 프레임부터 동물 얼굴·행동 | 첫 컷을 가장 센 장면으로 |
| 길이 | 상위 12편 9~77초, 대부분 36초 이하 | 12~37초 | 형식이 아닌 사건 길이로 |
| 출처 | 화면 아래 «출처: 프로그램 회차» (12편 중 9편) | 표기 없음 | 표기 필수 |

## 4. 위험 표시

| | 휴식시간 | 케찹츄 |
|---|---|---|
| 음성 해설 | **없음으로 판독** (원음 유지) | **없음으로 판독** (배경음악·효과음) |
| 글 해설 | 있음 | 있음(이야기까지 만듦) |
| 콘텐츠 ID 표시 | **64편 전부** | 0편 |
| 지역 차단 | 상위 12편 0 | 상위 12편 중 1편(러시아) |
| 재사용 판정 위험 | **높음** | **중간~높음** |
| 수익 | 공개 자료로 확인 불가. 권리자에게 갈 가능성이 있음 | 공개 자료로 확인 불가 |

조회가 나온다고 수익이 나는 것은 아닙니다. 이 두 채널이 수익을 내는지는 알 수 없습니다.

## 5. 금지

1. **음성 해설 없는 원본 재업로드.** 위 두 채널을 그대로 따라 하지 않습니다.
2. **로고·방송사 표시를 흐려서 가리기.** 휴식시간 일부 편(3·9·10위)에 흐림 상자가 보입니다. 단속을 피하는 행위로 보일 수 있습니다.
3. **출처 표기를 권리 해결로 여기기.** 표기는 기록일 뿐입니다. 방송사 소재는 콘텐츠 ID가 걸린다고 가정합니다.
4. **학대로 오해될 제목.** «리트리버 꼬리를 떼어보았다»(630만)는 가짜 꼬리 장난이지만 우리 소재 검사(제목 학대 오해)에 걸립니다.
5. **남의 실제 가족·동물에 없는 사실을 붙이기.** «가난한 집»은 근거가 확인되지 않은 설정입니다. 우리는 재미 표현과 사실 주장을 구분합니다.
6. **원본을 모르는 소재.** 케찹츄식 출처 불명 영상은 쓰지 않습니다. 소재마다 원본 주소와 권리 근거를 남깁니다.

## 6. 한계

- 해설 유무는 24편의 화면과 2편(케찹츄 3위·휴식시간 1위)의 소리 스펙트럼으로 판독했습니다. 음성을 전사하지 않았으므로 나머지 22편의 음성 해설 0은 확정이 아닙니다.
- «콘텐츠 ID 표시»는 유튜브 API의 licensedContent 값입니다. 실제 수익 배분이나 권리 주장 내용은 공개되지 않습니다.
- 원본 방송일은 GPT 웹조사 결과입니다(기사 근거는 재료 파일). 날짜와 조회수를 API로 직접 확인한 것은 이넉살 영상과 JTBC 클립 2편뿐입니다.
- «화제 때문에 터졌다»는 시점이 겹친다는 관찰이며 인과를 증명하지 않습니다.
