# 롱폼 기반 → 쇼츠 소득 시스템 기획 v0 (도구개발, 2026-10-15)

소유주 지시(10-15 밤): «@historyrewindjapan 처럼 롱폼을 기반으로 수익화 이후에 숏폼으로 소득을 얻는 시스템, 각 채널에 어떻게 적용할 수 있을까. 분석부터 기획까지.»
분석 원문: `reference/ja/historyrewindjapan/analysis.md`

## 0. 분석에서 나온 정정 하나

이 채널은 «롱폼을 잘라 쇼츠로 번다»가 **아니다.** 롱폼을 자른 쇼츠는 중앙값 4천 회였고, 롱폼과 같은 세계관의 **독립 «왜» 쇼츠**는 중앙값 10.9만 회였다(27배).
실제 시스템은 세 겹이다.

1. **롱폼 = 시기 닻 + 권위 + 시청 시간.** 대하 방영 회차에 맞춘 롱폼 히트 1편(9.9만)이 4,000시간 문턱을 넘길 만한 시청 시간을 만든다(추정).
2. **쇼츠 = 같은 세계의 상록 소재를 매일 3~6편.** 물건·구조·일상의 «왜»를 80~120초 동안 풀이해 구독을 모은다(두 달에 1.2만).
3. **공용 자산 파이프라인.** AI 그림·실측 지도·출처 정리를 롱폼과 쇼츠가 같이 쓴다. 쇼츠 원고는 새로 쓴다.

그래서 우리에게 옮길 것은 «롱폼 → 자르기» 도구가 아니라 다음 세 가지다. **한 세계관(주제 축) · 롱폼 시기 닻 · 독립 «왜» 쇼츠 틀.**

## 2. 1순위 시범: ja «戦国なぜ» 새 채널 (가칭)

### 세계관
戦国·江戸의 **물건·구조·일상의 왜**(갑옷·성·무기·음식·의례·직업). 사건사는 롱폼 몫이다. 歴史リワインド와 소재가 겹치니 **복제가 아니라 다른 각도**로 간다 — 후보: 江戸 서민 생활·직업(그쪽은 전장 위주), 또는 時代劇 속 장면의 진짜 모습(«時代劇でよく見る○○、実際は?»). 그러면 沼落ちシネマ 시청층과도 이어진다.

### 롱폼 (월 2~4편, 10~20분)
- 시기 닻: 2026 대하 「豊臣兄弟！」가 연말까지 방영 중이다 → 방영 회차 «그 다음» 편. 대하가 끝나면 다음 해 대하 인물로 갈아탄다.
- 「결말 먼저 → 왜로 되감기」 구조, 장 목차, 출처, 지도. 목적은 시청 시간 4,000시간과 권위다.

### 쇼츠 (하루 2~3편으로 시작, 80~120초)
- 원고 틀(분석 4장): 0~3초에 역설을 답부터 → 구조를 순서대로 → 닫는 한 줄 → 주제에 붙인 CTA.
- 하루 2~3편은 우리 재고 규칙(상시 14편)에 맞춘 시작값이다. 반응을 보고 올린다.

### 필요한 것과 우리에게 이미 있는 것

| 필요 | 있는 것 / 없는 것 |
|---|---|
| AI 그림·영상 | 볼케이노 그림 채널(뇌전구·군림보)이 그림+내레이션 쇼츠를 만든다(flow 무료 / evolink 유료). 롱폼은 볼케이노 «인물형 롱폼»(프반 전용, 계정 권한 확인 필요). **시대 고증 그림 품질은 시험해 봐야 안다** |
| 일본어 TTS | 볼케이노 lang=ja. 별도 엔진은 아직 미정 |
| 원고 | 틀 + 출처 정리 → gpt-ask(구독)로 초안, 사실 확인은 출처 URL 필수(정치 사실 규칙과 같은 결) |
| 소재 은행 | 없음 → 도구개발이 만들 1번(아래 3장) |
| 채널 | **새 채널 개설은 소유주 결정** |

## 3. 도구개발이 만들 것 (승인되면, 소유주가 실제로 쓸 것만)

1. **«왜» 소재 은행**: 戦国·江戸 물건·구조·일상 질문 100개, 출처 URL 1개 이상씩. 歴史リワインド가 이미 다룬 45개 주제를 빼서 겹침을 피한다(우리가 가진 그 채널 메타 전편으로 기계 대조).
2. **쇼츠 원고 지침서 + 검사기**: 분석 4장의 틀을 수치로 고정한다(첫 문장 답 제시·문장 길이·닫는 한 줄이 제목 역설을 닫는지·CTA 형식·출처 유무). N100 script-frames.json 방식이다.
3. **벤치 재측정**: 2주 뒤 이 채널을 다시 재서(같은 메타 수집) 급성장이 유지되는지 본다. 우리 시범의 비교 기준선이기도 하다.

## 4. 소유주가 정해 줄 것

1. ja 시범을 **새 채널**로 갈지, 沼落ちシネマ 안에서 시험할지(권고: 새 채널).
2. 세계관 각도: «江戸 서민 생활·직업» vs «時代劇 장면의 진짜 모습»(권고: 후자 — 우리 ja 시청층과 이어진다).
3. 그림 엔진 비용: flow(무료·볼케이노킷) 먼저 3편 시험 → 품질이 되면 진행.
4. 정치 쇼츠 «독립 질문형» 1주 A/B를 정치 세션에 넘길지.
