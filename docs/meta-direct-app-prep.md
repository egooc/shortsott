# 메타(인스타·페북) 직접 발행 앱 준비 (도구개발, 2026-10-29)

Blotato를 갱신하지 않기로 해서(10-29), 지금 인스타·페북·스레드 글은 올라가지 않고 «건너뜀»으로만 기록된다. 이 문서는 메타 개발자 앱을 만들어 우리 계정에 직접 올리기 위한 준비다. **앱 만들기·인증·로그인은 소유주가 직접** 하고, 코드는 그 뒤에 도구개발이 붙인다.

## 1. 결론부터

- **우리 계정에만 올린다면 앱 검수(App Review)와 비즈니스 인증 없이 시작할 수 있을 가능성이 높다.** 메타 문서상 검수·인증이 꼭 필요한 경우는 «앱 역할이 없는 다른 사람의 계정»에 올릴 때(고급 접근)다. 우리는 소유주 계정이 관리하는 계정에만 올린다.
- 단, 페이스북 쪽 문서에는 «모든 권한은 검수 필요»라는 문구도 있어 **개발 모드에서 공개 게시가 실제로 되는지는 첫 1편으로 실측해서 확정**한다(아래 5번).
- 영상은 공개 주소가 없어도 된다. 인스타·페북 모두 로컬 파일을 직접 올리는 «재개 가능 업로드(resumable upload)»가 있어서 Zernio·VPS 같은 중간 저장소가 필요 없다.

| 인스타 | meow_cinema21 (지구관측소 ko) | Blotato 연결이었음 → 건너뜀 |
| 인스타 | numaochicinema (沼落ちシネマ ja) | 〃 |
| 인스타 | shorteg006 (쇼핑) | 〃 |
| 페북 페이지 | ja·쇼핑 쪽 페이지(49235) | 〃 |
| 페북 | ko | 원래부터 수동(수익화가 개인 프로필에 있어 앱으로 못 올림) |
| 스레드 | 전부 | 원래 꺼짐(10-13 소유주 결정) |

인스타는 **프로페셔널 계정(비즈니스 또는 크리에이터)** 이어야 API로 올릴 수 있다. 앱 연결 전에 각 계정 설정에서 확인.

## 3. 앱 종류와 권한

- **앱 종류: «비즈니스(Business)»** 앱 하나에 두 제품을 붙인다.
  1. **Instagram API — 인스타그램 로그인(Business Login for Instagram)**: 페이스북 페이지 연결 없이 인스타 계정으로 바로 로그인하는 방식.
  2. **Facebook 로그인(비즈니스용) + Pages API**: 페이지 릴스 게시용.
- **필요 권한**

| 용도 | 권한 |
|---|---|
| 인스타 릴스 게시 | `instagram_business_basic`, `instagram_business_content_publish` |
| (선택) 인스타 댓글 읽기·고정 | `instagram_business_manage_comments` |
| 페북 페이지 릴스 게시 | `pages_show_list`, `pages_read_engagement`, `pages_manage_posts` |

- 페이스북 로그인 방식으로 인스타를 붙일 때의 옛 이름은 `instagram_basic`·`instagram_content_publish`다. 새로 만들면 위의 인스타 로그인 쪽 이름을 쓴다.

## 4. 접근 수준·검수·인증

| 단계 | 언제 필요한가 | 우리 |
|---|---|---|
| 표준 접근(기본) | 앱 역할(관리자·개발자·테스터)이 있는 사람의 계정 | **이걸로 시작** |
| 고급 접근 + 앱 검수 | 역할 없는 남의 계정에 올릴 때 | 필요 없음(예상) |
| 비즈니스 인증 | 고급 접근을 받을 때 | 필요 없음(예상) — 막히면 그때 |
| 앱 «라이브» 전환 | 개발 모드에서 공개 게시가 안 될 때 | 5번 실측 결과에 따라 |

- 한도(문서 기준): 페북 릴스는 페이지당 24시간에 30편, 인스타는 계정당 24시간 게시 한도가 있다(앱이 한도 조회 엔드포인트로 확인). 우리 편수(채널당 하루 2~3편)는 여유.

## 5. 첫 실측(도구개발이 할 일, 앱 연결 뒤)

1. 쇼핑 인스타(shorteg006)에 1편 게시 → 로그인 안 한 다른 계정·브라우저에서 보이는지 확인.
2. 페북 페이지에 릴스 1편 → 같은 확인.
3. 보이면 개발 모드 그대로 운영, 안 보이면 «라이브» 전환 조건(개인정보처리방침 주소 등)을 다시 보고.
4. 통과하면 `publish_routes.json` 의 메타 경로를 켜고, 발행기들은 지금 그대로(공용 `api()` 한 곳만 바뀜).

## 6. 소유주가 직접 할 클릭 순서

1. **developers.facebook.com** 에 소유주 페이스북 계정으로 로그인 → 처음이면 «개발자로 등록»(전화 인증이 나올 수 있음). 새 계정을 만들 필요는 없다.
2. **내 앱 → 앱 만들기** → 사용 사례에서 «기타» → 앱 유형 **«비즈니스»** → 앱 이름(예: 볼케이노 발행) → 비즈니스 포트폴리오는 «선택 안 함»으로 두어도 된다.
3. 앱 대시보드 → **제품 추가 → «Instagram»** → «인스타그램 로그인으로 API 설정».
   - «계정 추가»에서 meow_cinema21 · numaochicinema · shorteg006 을 차례로 로그인해 연결(각 계정의 «앱 및 웹사이트» 허용 화면에서 수락).
   - 각 계정이 테스터 초대를 받으면 인스타 앱 → 설정 → 앱 및 웹사이트 → **테스터 초대 수락**.
4. 같은 앱에 **제품 추가 → «Facebook 로그인(비즈니스용)»** → 권한 목록에서 `pages_show_list`·`pages_read_engagement`·`pages_manage_posts` 추가 → 대상 페이지 선택.
5. **앱 설정 → 기본 설정**: 개인정보처리방침 주소 칸만 채워 둔다(아무 공개 페이지라도 — 없으면 도구개발이 만들어 드림). 앱 시크릿은 화면에 띄우지 말고 **«보기»를 누르지 않은 채** 그대로 두면 된다.
6. 다 되면 관리자에게 «앱 만들었음»만 알려 주시면 됩니다. 토큰 발급은 소유주 화면에서 «토큰 생성» 버튼 한 번이 필요하고, 그 값은 채팅에 붙이지 말고 도구개발이 알려 드리는 파일 자리에 직접 넣는 방식으로 하겠습니다.

## 7. 하지 않는 것

- 새 페이스북·인스타 계정 만들기, 결제, 대행 서비스 가입 없음.
- 비즈니스 인증 서류 제출은 5번 실측에서 막힐 때만 다시 묻는다.
- 스레드는 꺼진 채로 둔다.
