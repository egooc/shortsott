## 0. 다섯 줄
1. **쇼츠는 글쓰기다.** 조회 안 나오는 이유는 편집·해시태그·시간이 아니라 대본. 편집은 대본의 시각화.
2. **후킹 = 결과·이유를 말하지 않는다.** 행동 묘사 / 의외성 / 궁금증 셋 중 하나, «오늘은…»·«이유는…» 설명형은 이탈.
3. **4단 구조**: 상황 1~2문장 → 긴장(짧은 문장·한 문장 한 사건·연결어·**감정 평가 금지, 행동만**) → 반전 → **엔딩은 나레이터 평가·요약 금지, 감정 한 문장으로 끊기**(«하지만» 여운).
4. **재사용 판정 회피 = 해설 + 3~4초 컷.** 원본 클립을 3초 넘게 통으로 쓰지 않는다, 공정사용은 해설·분석·짧은 사용량.
5. **분석 루틴**: 계속 시청함 70%·평균 조회율 100% 기준으로 후킹을 둘로 나눠 비교, 지표 나빠도 터진 소재는 «사람들이 좋아하는 소재»로 기록.
