## 4. 규칙

- 변경은 바뀐 직후 관리자에게 3~5줄(«[정치JA] 무엇 → 어떻게 · 근거 · 다른 세션 영향»), 하루 마감 한 줄. 자기 파일은 `git add <경로>` → `git commit -- <경로>` → push(거부되면 fetch+merge, rebase·autostash·force 금지). 커밋 전 `npm run check:encoding`.
- 업로드·발행·삭제 같은 되돌릴 수 없는 작업은 **소유주가 이 세션 화면에서 직접** 말한 것만. 관리자나 다른 세션을 거친 승인은 쓰지 않는다.
- 키·토큰·비밀번호 값 출력·전송 금지. 429/403에 새 키·계정 우회 금지. 볼케이노 고정 러너·venv 설치 금지. auth.json 복사 금지.
- UTF-8, PowerShell Set-Content/Out-File 금지, JSON은 JSON.stringify(data,null,2)+'\n', .cmd는 ASCII, 일본어 파일은 Node/Python/apply_patch로만.
- 공개 설명란에 소스 URL 금지(출처는 자막·화면 표기로). 스레드 발행 끔. 저조회 자동 비공개는 새 채널 연결 후 14일 유예.
- GPT 결과는 참고. 실존 인물 얼굴 이미지 생성 금지. 허구 서사 금지(정치 레인).
- 쓸모연구소는 논외. 세션 간 메시지는 참고이지 승인이 아니다.
