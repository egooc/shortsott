# 沼落ちシネマ 터진 편 해부 — 대리만족 문장 (2026-10-19)

큰제로 칼럼 Z3·Z4(관리자 경유 소유주 «이것도»). 다음 소재는 이 문장으로 고른다. 재부팅 복귀 뒤 첫 큐부터.

공통 축: **낮게 보이던 주인공이 실은 격이 위 — 통쾌함 다음에 절제(품격)가 온다.** 65세+ 남성 타깃에 «筋を通す»가 꽂힌다.
5위 出世しないと言われた居候(89,387, 暴れん坊将軍)도 같은 문장 — 얕보이던 식객의 정체.

## 같은 감정을 주는 다른 장면 후보 (한 장면 5분이면 충분)

- 地獄の辰 1화 902~955초 — 전과자로 얕보이는 辰이 상관에게 «칼집에 든 명검도 있다» → rinbox133ja 에 vicarious 기록(해설 2줄 시험편).
- 新･必殺仕事人 1화 (U63BadqUrUI, 제한 없음) — 약자 대신 갚아 주는 구조 자체가 대리만족. 장면 찾기는 10-20 09시 자막 창 이후.
- 桃太郎侍 — 상인·낭인으로 얕보이다 정체를 드러내는 장면(이미 120~128에 쓴 구간 밖에서).
- 暴れん坊将軍(SAMURAI VS NINJA, 일본만 차단) — 문장엔 가장 잘 맞지만 소유주 결정 대기.
