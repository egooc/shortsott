## 누락 요약
- 그룹 선택 판정식(#그룹명 Shorts탭 100만+ 절반·1달 이내, 차트·평판·트렌드) 없음. 적용 지점: 기획 게이트(새 그룹 착수 전).
- 갓 뜬 그룹은 피하고 100만+ 영상이 쌓인 검증 그룹 선호, 4세대 여돌 우선. 적용 지점: 소재 선정.
- 한국·일본 팬덤 둘 다 큰 그룹 선택. 적용 지점: 기획 게이트.
- 1황파/블루오션파 구분. 적용 지점: 기록만.
- 소재 고른 이유 3근거(유사영상 적음·신선도·댓글 포인트) 서술 부분 누락. 적용 지점: 소재 선정(spec.pattern 옆 한 줄).
- 원본 찾기 방법(구글렌즈→AI→시간대, AI 오답 주의)과 영어 검색, 원본은 조회수 몇만+ 우선 누락. 적용 지점: 소재 선정.
- +@ 추가영상은 틱톡 영어 키워드 검색. 적용 지점: 소재 선정.
- 관점 비틀기는 «조금만 비틀어도 충분». 적용 지점: 기획 게이트.
- 영어 자막으로 교육적 가치 얹기. 적용 지점: 템플릿.
- 찰칵 효과음 후킹 부분 누락. 적용 지점: 템플릿.
- 주제×템플릿 짝 실험(랭킹형·인스타형·음악형)과 미시/거시 결 확장, 랭킹형 제목 변형. 적용 지점: 기획 게이트(A/B 설계).
- 일본어 판 절차(일치율 낮추는 1분 컷편집, SRT 번역 재가져오기), 다국어(스페인어), 굿즈 쇼핑 태그. 적용 지점: 템플릿/업로드(ja 착수 때).
- 커뮤니티 인기글(펨코·더쿠·네이트판)을 소재 신호로 사용. 적용 지점: 소재 선정(대본형은 제외 유지).
- Grabbit 일괄 URL 복사 수집 도구. 적용 지점: 소재 선정.
- 프리랜서 지시서 4항목·채용·피드백, 원페이퍼 가이드, 자판기/선택과 집중, 데이터 매몰 경계, 15분 제작. 적용 지점: 기록만.
