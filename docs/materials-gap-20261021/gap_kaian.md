- 부분: 오답노트는 «한 편에 변수 딱 1개만 바꾼다»는 통제 규칙이 빠짐 → 분석(오답노트 양식에 «바꿀 것 1개» 칸)
- 없음: 목적 한 문장 «시청자의 어떤 결핍을 해결하는가» → 기록만(레인 카드)

### 칼럼 2 (쇼츠 50만개)
- 부분: 새 레인 초반엔 짧게 70% 방어 → 20→40→60초 점진 확장 순서 → 쇼츠 게이트(신규 레인 길이 램프)
- 부분: 시스템화의 목적은 천장이 아니라 저점(바닥) 올리기 → 기록만

### 칼럼 3 (카더라 8가지)
- 부분: 추천은 개별 영상 단위, 저품질 매일 업로드가 3초 이탈을 쌓아 오히려 해 → 쇼츠 게이트(품질 미달이면 재고보다 보류)
- 부분: 좋아요·구독 수는 점수가 아니고, 구독의 목적은 초기 시드 체류 데이터 → 기록만
- 부분: 진짜 타겟 확인은 스튜디오 [시청자층-많이 본 지역] → 분석(ja 채널 07:40 보고에 지역 1위)
- 부분: 쇼츠로 구독한 시청자는 알림이 꺼져 시드 트래픽이 안 됨 → 롱폼(롱폼 구독 유도가 알림 시드)
- 없음: 내 시청 기록은 내 채널 타겟에 영향 0 → 기록만

### 칼럼 4 (특허·신뢰도)
- 없음: 유튜브는 상대평가(zero-sum) — 지표가 좋아도 같은 주제 경쟁 편에 밀리면 1천에서 멈춤 → 분석(자기 지표만 보지 말고 경쟁 편과 비교)
- 없음: 섀도우밴은 없고 첫 48시간 타겟 탐색 뒤 포기 → 분석(업로드 뒤 48h 점검 창)
- 부분: 샌드박스 탐색 기간은 노력으로 단축 불가 → 기록만
- 부분: 방치 채널에 갑자기 업로드하면 해킹 스팸 의심 영구 차단 위험 → 채널 운영(휴면 채널 재가동은 커뮤니티 글부터, K15와 연결)
- 없음: 확산 4단계·평가 요소 5 → 기록만

### 칼럼 6 (A×B=C)
- 없음: 브랜디드 쇼츠 — 제작비와 2차 활용 라이선스 분리 과금, 저작권은 제작자, 계약서 요구; 광고주는 나노 채널의 흡입력을 산다 → 수창(브랜디드 들어올 때 계약 원칙). 기록만

### 칼럼 7 (블루오션·5단계)
- 부분: 레벨 2 예시 «명화관(실화 탈옥 영화) 2,300만» — 우리 명화관 레인과 동명 레퍼런스 → 발굴(레퍼런스 채널 등록)
- 없음: 조회 그래프가 40일 뒤 치솟는 경우도 있다 → 채널 운영(저조회 24h 자동 비공개 기준과 충돌, 지연 반등 사례 추적 B)
- 부분: 외주 전환은 월 500(최소 100) 복제 가능 현금흐름 뒤 → 기록만
- 없음: 저자의 새 일본 채널이 한국보다 빨리 컸다(한 달 100만 원) → 기록만
