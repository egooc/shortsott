# 기획 가이드 표준 — 상위 2채널 × 인기 12편 (발굴 운용판, 2026-10-19)

관리자 §7(소유주 10-19 B 팬튜브 화면 지시)의 틀을 발굴 쪽에서 쓰는 방법이다. 레인을 고른 **뒤** 기획 가이드와 시험편 채점에 쓴다. 레인 선정(카테고리 카드)은 지금처럼 «소형 채널 최근 15편 중앙 + 신규 채널 1만+ 편수»로 한다.

## 0. 가이드·카드 머리 두 줄 (큰제로 칼럼, 10-19 추가 — `docs/keunzero-column-rules-20261019.md`)

모든 기획 가이드와 카테고리 카드는 맨 위에 아래 두 문장을 먼저 쓴다. 이 두 줄이 없으면 그 아래 표는 관찰 일기다.

1. **채널 방향성 한 문장(5W1H):** «[누가]가 [언제/어떤 상황의] [누구]에게 [무엇을] [어떻게] 전함으로써 [왜] 한다».
   - 편집 기법 낱말(컷·자막·TTS·줌 등)은 쓰지 않는다.
   - «~하려고 한다»가 아니라 «~한다»로 단정한다.
2. **레인의 대리만족 한 문장:** 시청자가 현실에서 못 느끼는 어떤 감정을 이 레인이 대신 느끼게 하는가.
   - 작품명·인물명은 쓰지 않는다.
   - 24편 시트의 7번 항목(아래 2-1)에서 가장 많이 겹치는 것을 올린다.

## 1. 고르기

- **채널 2곳:** 누적이 아니라 **최근 15편 중앙**으로 고른다. 2곳 중 1곳은 소형(구독 1만 안팎 이하)으로 넣는다. 결이 다른 형식(목록형·수면용 등)은 빼고 이유를 적는다.
- **인기 12편:** 최근 **90일** 안, 게시 72시간 이상, 레인 길이 조건(롱폼 8분+ / 쇼츠 3분 이하) 안에서 조회 상위 12편을 고른다. 주제가 레인 밖인 편은 ※로 표시하고, 구조 참고로만 쓴다.
- **자료:** Data API(조회·길이·제목)만 쓴다. 0원이다.

## 2. 보기

- **프레임 시트:** 장면 전환과 일정 간격으로 뽑고 타임코드를 박는다. GPT 분석은 **시트를 첨부했을 때만** 돌린다. 제목만 넣은 분석은 약했다(B GUIDE «참고만»).
- **길이 × 조회 분포:** 해당 채널들의 90일 전 편을 길이 구간별 편수·중앙·100만+ 편수로 정리한다(팬튜브 실측 표 형식).
- **화면·해설 속성:** 고정 제목, TTS 해설(전편/첫 줄/없음), 반응 자막, 원본 직접 컷, 댓글 카드, 화면 틀. 해설 유무는 앞 12초 Speechmatics로 가린다. 유튜브 자막 요청이 아니다.

### 2-1. 레퍼런스 시트 7항목 (편마다, 큰제로 칼럼 10-19 추가)

| # | 항목 | 적는 법 |
|---|---|---|
| ① | 무슨 이야기(본질) | 한 줄. 겉 소재가 아니라 «무엇에 관한 이야기인가» |
| ② | 시작-전개-결말 | 세 칸, 각 한 줄 |
| ③ | 감정 흐름 | 시작 감정 → 바뀌는 지점(초 또는 %) → 끝 감정 |
| ④ | 후킹 방식 | 첫 1~3초에 무엇으로 붙잡나(질문·결과 먼저·이상한 장면 등) |
| ⑤ | 지속 유도 장치 | 끝까지 보게 하는 미해결 질문·예고·카운트 |
| ⑥ | 참여 유도 | 댓글·공유를 부르는 지점(편 가르기·공감 질문·정답 맞히기 등) |
| ⑦ | **★핵심 대리만족 한 문장** | «시청자가 현실에서 못 느끼는 ___을 대신 느낀다». 작품명·인물명 금지 |

- ⑦이 비면 그 편은 분석이 끝나지 않은 것이다.
- 24편의 ⑦을 묶어 가이드 머리의 «레인의 대리만족 한 문장»(0절 2)을 만든다.

### 2-2. 제목 10패턴 분류 (하늘구름땅바람 칼럼, 10-19 추가 — `docs/sky-column-rules-20261019.md`)

24편 제목마다 아래 10패턴 가운데 해당하는 것을 모두 표시한다(복수 허용). 가이드 끝에 «패턴별 편수와 그 편들의 조회 중앙»을 적고, 몰린 패턴 상위 3개를 우리 제목 틀로 쓴다.

| 패턴 | 예 (칼럼 S1 원문 기준) |
|---|---|
| ① 결과 숨김 | «~했더니», «벌어진 일», «~의 최후» |
| ② 이유를 판다 | «~하는 이유», «진짜 이유», «비밀» |
| ③ 보는 사람 저격 | «여자들만», «직장인», «90년대생» |
| ④ 숫자 | «TOP6», «7년차», «vs» |
| ⑤ 금지·경고 | «절대 따라 하지 마세요», «~주의» |
| ⑥ 말하다 만다 | 핵심 직전에서 끊기(«쇼츠 최적화 배우»), 말줄임 |
| ⑦ 실화 도장 | «실제», «바디캠», «썰» |
| ⑧ 친근 말투 | «ㅋㅋ», «ㄷㄷ», «ㅠ» |
| ⑨ 대사 그대로 | 화면 속 대사를 따옴표 없이 혹은 따옴표로 |
| ⑩ 최상급 | «역대급», «소름» — 범위를 한정하고 남발 금지 |

S2 체크도 함께 적는다: 앞 10자 안에 핵심 낱말이 있는가, 전체 15자 안팎인가, 결과를 드러내지 않는가, 설명형·해시태그 도배가 아닌가.

## 3. 대본 구조 3질문 (K8, 10-19 추가 — 도구개발과 같은 항목)

12편마다 아래 세 칸을 채운다. **문장은 베끼지 않는다.** 구조만 가져온다(시맨틱 불일치·표절 필터).

| # | 질문 | 적는 법 |
|---|---|---|
| Q1 | **첫 문장과 자극 심리** | 첫 문장 원문 요지 + 유형(상황 단정 / 어그로 / 질문 / 결론 먼저) + 건드리는 심리(호기심·손해 회피·의외성·공감·분노 등) |
| Q2 | **반복되는 고유명사·전문 용어 3개** | 의도적으로 되풀이되는 낱말 3개와 등장 횟수. 제목·태그·설명 첫 줄과 겹치는지 표시 |
| Q3 | **이탈 방지 질문·전환 패턴** | 중간에 다시 붙잡는 문구(«그런데», «여기서 반전», 질문 던지기 등)의 위치(초 또는 %)와 패턴 이름 |

- **원천:** 전사 단어 시각을 쓴다.
  - 유튜브 자막은 **배정된 자막 창(09시) 안에서만** 받는다.
  - 창 밖이거나 429가 난 날에는 Speechmatics ko·ja로 대신한다.
  - 우회 요청은 금지다.
- **Q4 대본 교배(큰제로 칼럼, 10-19 추가):** 24편에서 두 편을 고른다.
  - **뼈대 편:** 구조가 좋은 편. 시작·전개·결말 칸이 가장 깔끔한 편이다.
  - **욕구 편:** 욕구를 가장 세게 자극한 편. 댓글·조회가 튄 편이다.
  - 뼈대 편의 기승전결 뼈대 위에 욕구 편의 심리 로직을 얹는다. 심리 로직은 «몇 초(몇 %) 지점에서, 시청자가 모르던 어떤 정보가 풀리며, 어떤 욕구가 해소되나»로 적는다.
  - 결과는 «우리 편 뼈대 4줄 + 정보 비대칭이 풀리는 지점 1줄»로 가이드에 남긴다. 문장은 베끼지 않는다.
- **결과 칸:** 12편의 Q1 유형 분포, Q2 공통 낱말, Q3 평균 위치를 «원고 지시» 세 줄로 바꿔 가이드 끝에 적는다.
