# 기획 가이드 표준 — 상위 2채널 × 인기 12편 (발굴 운용판, 2026-10-19)

관리자 §7(소유주 10-19 B 팬튜브 화면 지시)의 틀을 발굴 쪽에서 쓰는 방법이다. 레인을 고른 **뒤** 기획 가이드와 시험편 채점에 쓴다. 레인 선정(카테고리 카드)은 지금처럼 «소형 채널 최근 15편 중앙 + 신규 채널 1만+ 편수»로 한다.

## 1. 고르기

- **채널 2곳:** 누적이 아니라 **최근 15편 중앙**으로 고른다. 2곳 중 1곳은 소형(구독 1만 안팎 이하)으로 넣는다. 결이 다른 형식(목록형·수면용 등)은 빼고 이유를 적는다.
- **인기 12편:** 최근 **90일** 안, 게시 72시간 이상, 레인 길이 조건(롱폼 8분+ / 쇼츠 3분 이하) 안에서 조회 상위 12편을 고른다. 주제가 레인 밖인 편은 ※로 표시하고, 구조 참고로만 쓴다.
- **자료:** Data API(조회·길이·제목)만 쓴다. 0원이다.

## 2. 보기

- **프레임 시트:** 장면 전환과 일정 간격으로 뽑고 타임코드를 박는다. GPT 분석은 **시트를 첨부했을 때만** 돌린다. 제목만 넣은 분석은 약했다(B GUIDE «참고만»).
- **길이 × 조회 분포:** 해당 채널들의 90일 전 편을 길이 구간별 편수·중앙·100만+ 편수로 정리한다(팬튜브 실측 표 형식).
- **화면·해설 속성:** 고정 제목, TTS 해설(전편/첫 줄/없음), 반응 자막, 원본 직접 컷, 댓글 카드, 화면 틀. 해설 유무는 앞 12초 Speechmatics로 가린다. 유튜브 자막 요청이 아니다.

## 3. 대본 구조 3질문 (K8, 10-19 추가 — 도구개발과 같은 항목)

|---|---|---|
| Q1 | **첫 문장과 자극 심리** | 첫 문장 원문 요지 + 유형(상황 단정 / 어그로 / 질문 / 결론 먼저) + 건드리는 심리(호기심·손해 회피·의외성·공감·분노 등) |
| Q2 | **반복되는 고유명사·전문 용어 3개** | 의도적으로 되풀이되는 낱말 3개와 등장 횟수. 제목·태그·설명 첫 줄과 겹치는지 표시 |
