# 옛 터진 소재 채굴 큐 1회 — 팬튜브·린박스 ja·롱투숏 각 10개 (2026-10-20, 발굴)

- **근거:** 큰제로 Z8과 devo V10 «소재 고갈 3법»(1~2년 전 해외 터진 영상 / 연관 주제 확장 / 국내 터진 영상 재가공). 10-19 큐에 있었지만 0회였다.
- **조건:**
  - 게시 시기: **2024-10-01~2025-10-20**(오늘 기준 1~2년 전)
  - **조회 100만+**
  - 길이 조건 없음
- **적는 법:** 겉모습이 아니라 **감정 핵심 한 줄**로 적는다(큰제로 «대리만족 한 문장» 방식). 각 레인 세션은 «감정 핵심»을 새 소재에 옮겨 담는다. 원본을 그대로 다시 올리지 않는다.
- **방법:**
  - Data API search(기간·조회순) → videos로 조회·댓글을 확인했다.
  - 우리 문서·설정에 같은 id가 있는지 grep했다(전부 0건 = 미사용).
  - 롱투숏은 같은 주제의 한국어 쇼츠 100만+ 편수를 검색으로 셌다.
  - 0원, GPT 0건, 자막 요청 0건.
- **다음 회:** 11-20 전후. 같은 기간을 한 달 밀고, 이미 쓴 id는 뺀다.
