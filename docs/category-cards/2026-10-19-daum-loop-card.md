# 다음(Daum) 숏폼 «루프» 카테고리 카드 (2026-10-19, 발굴) — 1쪽

요청(관리자 10-19, 소유주 «분석해야지»): 어떤 카테고리가 잘 나오는지, 우리 레인과 겹치는 칸, 입점 조건을 본다. 가입·신청은 하지 않는다.
- **조사 방법:**
  - GPT 1건(웹 검색, 출처 URL 대조)
  - 다음 홈 «오늘의 루프» 칸 직접 수집(7회 요청, 같은 10편)
- **한계:**
  - 루프는 **조회수를 밖으로 공개하지 않는다**(홈 데이터에 재생 수 필드 없음).
  - 카카오도 장르별 성과·이용자 수를 발표한 적이 없다.
  - 그래서 «카테고리별 조회 분포»는 잴 수 없고, **편성(탭)과 노출 표본**으로 대신한다.

## 결론

- 루프는 **조회 분포를 밖에서 잴 수 없는 플랫폼**이다. 카테고리 성과는 입점 뒤 우리 채널 통계로만 알 수 있다.
- 공개 근거로 보면 **정치 해설 쇼츠와 동물·해외 영상 재편집**이 «개인 창작자가 홈에 노출되는 칸»과 겹친다. 이용층(40~50대 이용률 상대 우위)도 정치와 맞는다.
- **B4(입점 신청) 권고:**
  - 지금처럼 «쇼츠 레인이 하나라도 안정되면 신청»을 유지한다.
  - 신청 채널은 **정치 쇼츠 1순위, N100·해짜형 2순위**다.
  - 수익 단가 0.26원은 근거 없는 숫자이므로 결정 근거에서 뺀다.
