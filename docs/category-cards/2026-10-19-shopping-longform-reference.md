## 2. 상품 포장 방식 (쿠팡 파트너스·유튜브 쇼핑 태그)

| | 헤이두 | 이참에 살림 |
|---|---|---|
| 제휴 | 쿠팡 파트너스 고지 1줄. 최근 15편 중 10편 | **쿠팡 링크 7/12편 + 유튜브 쇼핑 태그 2/12편**(최근 8월 편들은 쇼핑 태그로 전환, «쇼핑 태그를 통해 구매 시 수수료» 고지) |
| 설명란 순서 | 공감형 소개 문단 → 해시태그 → 파트너스 고지 → **«시각 + 상품명 + 쿠팡 링크»** 목록(다이소 품은 품번·가격) → 자체 브랜드 특가 링크 → 팁 목차(Index) | 한 줄 요약 → **«↓ 영상 속 제품 정보 ↓»** → 챕터마다 «시각 [특징] 상품명 \| 품번 / 가격» → 고지 → 해시태그 |

| 썸네일 | 팁 사진 4~6장 콜라주, 가운데 작은 흰 글씨 한 줄 + 영어 부제. 다이소 로고는 다이소 편에만. 얼굴 없음 | **상품 하나 큰 클로즈업 + «Top13·Best7» 개수 배지 + 2줄 큰 글씨(노랑/빨강) + 다이소 로고**. 얼굴 없음 |
| 제목 틀 | «[비용 0·효과 훅] 살림 꿀팁 **N가지**🌿 \| 알아두면 평생 써먹는 ~ 아이디어💡 / 영어 제목» | «"[감탄 인용]" 다이소 [신상·꿀템·실수템] **N가지** (보이면 무조건 집으세요) \| 다이소추천템 \| 내돈내산 \| 삶의 질 상승템» |

## 3. 쓸모연구소 8~10분 «살림 실수 n가지»에 주는 시사점

- **길이와 개수:** 8~10분이면 팁 **10~12가지**(하나 약 50초)가 두 채널 실측과 맞는다. 쇼츠 1편(40~60초)이 팁 1개에 해당하므로, 쇼츠 10~12편을 묶으면 바로 한 편이 된다.
- **틀 선택:**
  - «실수 n가지»를 그대로 쓴 상위 편은 두 채널에 없다. 가까운 것은 이참에 살림의 «다이소의 역대급 **실수템** 11가지»(26.3만)다.
  - 상위 편 대부분은 «꿀팁·꿀템 N가지 + 비용 0/삶의 질» 틀이다.
  - 권고: «살림 실수 N가지»를 A로, «돈 안 드는 살림 꿀팁 N가지»를 B로 두고 포장 A/B를 한다(롱폼 포장 교체 규칙).
- **상품 노출은 이참에 살림 방식이 쇼핑 제휴에 맞다:**
  - 챕터마다 상품명·가격 자막을 화면 왼쪽 위에 상시로 띄운다.
  - 설명란에 «시각 + 상품 + 링크/쇼핑 태그» 목록을 둔다.
  - 썸네일은 상품 하나 클로즈업에 개수 배지를 단다.
  - 단 쓸모연구소의 파트너스 표기 규칙(우상단 광고 표시만, 10/12 소유주)과 겹치는지는 쇼핑 세션이 확인한다.
- **해설:** 둘 다 사람 목소리 해설이 끌고 간다(60~97%). 소형 채널(이참에 살림)은 인사 없이 첫 문장에 이득과 개수를 박는다.
- **확인한 주의점:** 두 채널 모두 실제 사용 장면을 직접 찍는다. 중국 쇼핑 영상을 섞는 우리 쇼츠 소스로 롱폼을 만들면 이 «실사용» 결이 약해진다. 시험편은 실사용 장면 비중을 따로 잰다.
