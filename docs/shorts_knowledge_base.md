# 쇼츠 운영 지식 베이스 — AI 학습용 데이터 & 실무자 가이드

> 출처: 마라하기 유튜브 쇼츠 강의 스크립트  
> 목적: 강의 내용을 단순 요약하지 않고, AI가 참조·학습·재사용할 수 있는 규칙 데이터와 실무자가 바로 실행할 수 있는 운영 가이드로 재구성한다.  
> 제외: 강사 소개, 수익 인증, 도입부, 세일즈 멘트, 감정적 동기부여.  
> 포함: 알고리즘 이해, 카테고리 발굴, 결 맞추기, 소재 분석, 대본 재구성, 일치율 제거, 가이드라인 검수, 외주 지시, 자동화 프롬프트, 업로드 후 분석.

# 0. 문서 사용 원칙

## 이 문서의 역할

이 문서는 두 가지 용도로 사용한다.

### 1) AI 학습용 데이터

AI가 쇼츠 운영 업무를 수행할 때 참조할 수 있는 규칙, 판단 기준, 작업 순서, 입력·출력 구조를 제공한다.

활용 예:

- 쇼츠 소재 평가
- 터진 영상 분석
- 대본 재구성
- 후킹 문장 생성
- 와우포인트 추출
- 가이드라인 위험 표현 탐지
- 외주 지시서 생성
- 업로드 후 성과 원인 분석

### 2) 실무자 가이드

실무자가 실제 업무에서 따라 할 수 있는 SOP, 체크리스트, 판단 기준으로 사용한다.

활용 예:

- 신규 채널 기획
- 카테고리 리서치
- 해외 소재 발굴
- 국내 벤치마킹
- 작가/편집자 업무 지시
- 업로드 전 검수
- 실패 원인 분석

# 1. 핵심 운영 철학

## 원칙 ID: CORE-001

### 원칙명
검증된 반응을 재구성한다.

### 설명
쇼츠 운영은 완전한 창작보다 검증된 반응의 재구성에 가깝다. 이미 높은 조회수를 만든 영상은 시청자 반응이 검증된 소재다. 실무자는 그 영상을 그대로 복제하지 않고, 반응을 만든 구조를 분석한 뒤 내 채널에 맞게 재구성해야 한다.

### 실무 판단 기준

- 조회수가 이미 검증된 영상인가?
- 댓글과 공유 등 감정 반응이 있는가?
- 내 채널의 결과 맞는가?
- 원본과 충분히 다르게 재구성할 수 있는가?
- 반복 소재로 확장 가능한가?

### AI 작업 지시

AI는 원본 콘텐츠를 복제하지 말고 다음 요소를 분리해 분석해야 한다.

- 핵심 사건
- 시청자 감정 반응
- 와우포인트
- 후킹 구조
- 대본 구조
- 위험 표현
- 재구성 가능 지점

### 금지 사항

- 원본 문장 그대로 사용
- 원본 자막 그대로 사용
- 단순 번역만 수행
- 장면 순서 그대로 복제
- 제목 구조 그대로 복제

# 2. 알고리즘 이해 데이터

## 원칙 ID: ALG-001

### 원칙명
알고리즘은 영상 자체보다 시청자 반응을 본다.

### 설명
유튜브 알고리즘은 영상을 인간처럼 완전히 이해하는 것이 아니라, 시청자의 행동 반응을 수집해 노출 여부를 판단한다. 따라서 영상 제작의 목표는 알고리즘을 직접 설득하는 것이 아니라 시청자의 긍정 행동을 설계하는 것이다.

### 긍정 반응 데이터

| 반응 | 의미 | 실무 해석 |
|---|---|---|
| 클릭 | 관심 발생 | 제목/첫 장면/주제가 작동함 |
| 긴 시청 지속 | 이탈 방어 | 전개가 버틸 만함 |
| 완주 | 끝까지 볼 이유 있음 | 이야기 구조가 유지됨 |
| 반복 시청 | 장면 매력 또는 정보 밀도 있음 | 재시청 포인트 존재 |
| 좋아요 | 만족 또는 공감 | 감정 반응 발생 |
| 구독 | 채널 결 신뢰 | 다음 콘텐츠 기대 발생 |
| 공유 | 강한 감정 또는 유용성 | 확산 가능성 높음 |
| 다음 영상 시청 | 채널 결 강화 | 알고리즘 학습에 유리 |

### 부정 반응 데이터

| 반응 | 의미 | 실무 해석 |
|---|---|---|
| 바로 나감 | 초반 후킹 실패 | 첫 1~3초 수정 필요 |
| 초반 이탈 | 기대 불일치 | 제목/첫 장면/내용 불일치 가능 |
| 중간 이탈 | 전개 약함 | 중반 갈등·궁금증 부족 |
| 관심 없음 | 타깃 불일치 | 잘못된 시청자에게 노출 또는 결 불일치 |
| 추천 안 함 | 강한 거부감 | 소재/표현/톤 문제 |
| 신고 | 정책 또는 감정 위험 | 가이드라인 재검수 필요 |
| 유튜브 종료 | 매우 부정적 반응 | 영상 피로도 또는 불쾌감 가능 |

### 실무 체크 질문

- 첫 3초 안에 손가락을 멈출 이유가 있는가?
- 끝까지 봐야 이해되는 정보나 반전이 있는가?
- 반복해서 보고 싶은 장면이 있는가?
- 공유하고 싶은 감정이 있는가?
- 이 영상을 본 사람이 다음 영상도 볼 이유가 있는가?

### AI 출력 요구사항

AI가 영상을 분석할 때는 반드시 아래 형식으로 출력한다.

```json
{
  "algorithm_analysis": {
    "likely_positive_reactions": [],
    "likely_negative_reactions": [],
    "first_3_seconds_risk": "",
    "retention_driver": "",
    "completion_driver": "",
    "share_driver": "",
    "channel_fit_score": 0
  }
}
```

# 3. 결 맞추기 데이터

## 원칙 ID: FIT-001

### 원칙명
채널은 특정 시청자 집단에 반복 노출되어야 한다.

### 설명
채널 안에 너무 많은 주제가 섞이면 알고리즘이 누구에게 영상을 보여줘야 할지 판단하기 어려워진다. 채널은 하나의 대카테고리보다 더 좁은 키워드와 감정 결을 가져야 한다.

### 나쁜 구조

```text
스포츠 채널
├─ 축구
├─ 야구
├─ 농구
├─ 골프
├─ 배구
└─ 스키
```

문제: 모두 스포츠지만 시청자 집단이 다르다.

### 좋은 구조

```text
축구
└─ 프리미어리그
   └─ 손흥민
      └─ 극적인 골 / 논란 장면 / 감동 인터뷰
```

장점: 시청자 관심사가 명확하고 반복 반응을 얻기 쉽다.

### 결 판단 기준

| 항목 | 질문 |
|---|---|
| 주제 일관성 | 기존 영상들과 같은 관심사인가? |
| 감정 일관성 | 기존 시청자가 기대하는 감정인가? |
| 키워드 일관성 | 채널이 학습 중인 키워드와 연결되는가? |
| 포맷 일관성 | 자막, 편집, 나레이션 톤이 이어지는가? |
| 다음 시청 가능성 | 이 영상을 본 사람이 다음 영상도 볼까? |

### AI 출력 요구사항

```json
{
  "channel_fit": {
    "main_category": "",
    "sub_category": "",
    "pinpoint_keyword": "",
    "viewer_group": "",
    "fit_score": 0,
    "fit_reason": "",
    "risk_of_mixed_signal": ""
  }
}
```

# 4. 카테고리·키워드 발굴 SOP

## SOP ID: CAT-001

### 목적
신규 채널 또는 신규 소재를 만들기 전에, 시장에서 반복적으로 반응이 검증된 키워드를 찾는다.

### 입력값

- 관심 대카테고리
- 참고 채널 URL
- 참고 영상 URL
- 국가/언어권
- 목표 플랫폼

### 작업 순서

1. 대카테고리를 정한다.
2. 관련 중카테고리와 세부 키워드를 확장한다.
3. 유튜브 쇼츠, 틱톡, 인스타 릴스에서 검색한다.
4. 최근 30~90일 내 터진 영상이 있는지 확인한다.
5. 같은 키워드로 여러 영상이 터졌는지 확인한다.
6. 댓글에서 반복 감정을 추출한다.
7. 국내에 이미 포화인지 확인한다.
8. 해외에는 터졌지만 국내에는 덜 퍼진 소재를 분리한다.
9. 20개 이상 소재 확장 가능성이 있는 키워드만 남긴다.
10. 후보 키워드를 점수화한다.

### 키워드 점수 기준

| 평가 항목 | 점수 기준 |
|---|---|
| 조회수 강도 | 100만+ 영상이 반복되는가 |
| 최신성 | 최근에도 터지는가 |
| 반복성 | 여러 채널에서 반복되는가 |
| 감정성 | 댓글 반응이 강한가 |
| 확장성 | 20개 이상 소재화 가능한가 |
| 국내 공백 | 국내에 덜 퍼졌는가 |
| 결 적합성 | 운영 채널과 맞는가 |

### AI 출력 요구사항

```json
{
  "keyword_research": [
    {
      "keyword": "",
      "category": "",
      "evidence_of_demand": "",
      "recent_trend_strength": 0,
      "repeatability_score": 0,
      "emotion_score": 0,
      "domestic_gap_score": 0,
      "channel_fit_score": 0,
      "final_score": 0,
      "decision": "use / hold / reject"
    }
  ]
}
```

# 5. 터진 영상 분석 SOP

## SOP ID: VIRAL-001

### 목적
조회수가 높게 나온 영상에서 반응을 만든 구조를 추출한다.

### 입력값

- 원본 영상 URL
- 영상 제목
- 조회수
- 업로드일
- 댓글 일부
- 자막 또는 대본
- 채널 평균 조회수

### 분석 순서

1. 채널 평균 대비 조회수가 높은지 확인한다.
2. 첫 3초 장면을 기록한다.
3. 와우포인트를 찾는다.
4. 영상의 핵심 사건을 한 문장으로 요약한다.
5. 댓글에서 반복 감정을 추출한다.
6. 시청자가 끝까지 봐야 하는 이유를 찾는다.
7. 반복 시청을 유도할 장면이 있는지 본다.
8. 원본과 다른 방식으로 재구성 가능한지 판단한다.
9. 가이드라인 위험 요소를 표시한다.
10. 내 채널에 적용할지 결정한다.

### 분석 출력 형식

```json
{
  "viral_video_analysis": {
    "source_url": "",
    "title": "",
    "view_count": 0,
    "relative_performance": "above_average / average / unknown",
    "core_event": "",
    "first_3_seconds": "",
    "wow_points": [],
    "viewer_emotions": [],
    "comment_insights": [],
    "why_it_worked": "",
    "reuse_potential": 0,
    "guideline_risks": [],
    "recommended_decision": "use / modify / reject"
  }
}
```

# 6. 와우포인트 추출 SOP

## SOP ID: WOW-001

### 목적
영상에서 시청자의 손가락을 멈추게 할 장면을 찾고, 초반 후킹으로 재배치한다.

### 와우포인트 정의

와우포인트는 시청자가 감정적으로 반응하는 가장 강한 순간이다.

### 후보 유형

- 반전이 드러나는 순간
- 누군가 놀라는 순간
- 결과가 공개되는 순간
- 사고나 충돌 직전
- 억울함, 분노, 감동이 생기는 순간
- 시청자가 “왜?”라고 묻게 되는 장면
- 댓글에서 반복적으로 언급된 장면

### 작업 순서

1. 원본을 처음부터 끝까지 본다.
2. 감정이 가장 크게 움직이는 장면을 3개 표시한다.
3. 각 장면이 초반에 배치 가능한지 판단한다.
4. 가장 강한 장면을 첫 1~3초 후보로 선택한다.
5. 초반에 보여준 장면의 설명을 뒤에서 풀어낸다.
6. 결말까지 궁금증이 유지되도록 순서를 재배치한다.

### AI 출력 요구사항

```json
{
  "wow_point_extraction": {
    "wow_point_candidates": [
      {
        "scene": "",
        "emotion": "",
        "why_it_stops_scroll": "",
        "can_be_opening_hook": true,
        "risk": ""
      }
    ],
    "selected_opening_wow_point": "",
    "recommended_sequence": []
  }
}
```

# 7. 대본 재구성 SOP

## SOP ID: SCRIPT-001

### 목적
원본의 검증된 반응 구조를 유지하되, 문장·감정선·장면 순서·표현을 새롭게 구성한다.

### 입력값

- 원본 대본
- 원본 영상 설명
- 선택한 와우포인트
- 목표 채널 카테고리
- 목표 시청자
- 금지 표현
- 원하는 톤

### 작업 순서

1. 원본 사건을 한 문장으로 요약한다.
2. 원본 문장을 모두 분해한다.
3. 와우포인트를 초반에 배치한다.
4. 첫 3초 후킹 문장을 쓴다.
5. 상황 설명을 짧게 정리한다.
6. 중반부에 궁금증 또는 갈등을 유지한다.
7. 후반부에 결과 또는 반전을 배치한다.
8. 마지막에 감정 정리 또는 댓글 유도 문장을 넣는다.
9. 원본과 겹치는 문장을 제거한다.
10. 가이드라인 위험 표현을 순화한다.

### 대본 구조 템플릿

```text
[0~3초: 강한 장면/후킹]
시청자가 멈출 만한 결과 또는 반전 먼저 제시

[3~10초: 상황 설명]
누가, 어디서, 무엇을 하고 있었는지 짧게 설명

[10~25초: 갈등/궁금증]
왜 이 장면이 중요해지는지 설명

[25~40초: 전개]
사건의 변화와 감정 증폭

[40초 이후: 결과/반전]
결과 공개, 반응 정리, 여운 남기기
```

### AI 출력 요구사항

```json
{
  "rewritten_script": {
    "hook": "",
    "setup": "",
    "development": "",
    "turning_point": "",
    "ending": "",
    "caption_lines": [],
    "voiceover_script": "",
    "changed_from_original": []
  }
}
```

# 8. 일치율·중복도 제거 SOP

## SOP ID: DIFF-001

### 목적
원본과 너무 비슷하게 보이거나 들리지 않도록 대본, 장면, 자막, 편집 구조를 재설계한다.

### 변경 대상

| 대상 | 변경 방식 |
|---|---|
| 문장 | 완전히 새 문장으로 재작성 |
| 키워드 | 유사 의미의 다른 표현 사용 |
| 장면 순서 | 와우포인트를 앞으로 이동 |

### 최소 변경 기준

- 초반 3초의 구성 방식이 달라야 한다.

- 자막 표현이 달라야 한다.
- 장면 순서가 최소 30% 이상 재배치되어야 한다.
- 위험한 표현은 순화되어야 한다.

> 쇼츠 운영은 검증된 시청자 반응을 찾고, 내 채널의 결에 맞게 와우포인트·대본·장면 순서·표현을 재구성한 뒤, 가이드라인 안에서 반복 업로드하고 데이터를 다시 학습하는 과정이다.
