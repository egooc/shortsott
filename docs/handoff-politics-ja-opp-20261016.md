- 사실만·허구 금지·출처 URL·명예훼손 3요건(공공성·공익성·진실성). «공격적»은 **충돌 장면 선택**으로 내고, 해설·제목에 조롱어·감정어는 넣지 않는다(상위 편 제목 감정어 0 실측).
