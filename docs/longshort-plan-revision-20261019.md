- **상태:** 초안이다. 소유주 «롱투숏도 기획 수정해서 더 지켜볼 거»(10-19 11:0x)에 따른 것이고, 소유주 말이 있기 전에는 집행하지 않는다.

  - 지구관측소 공개 쇼츠 실측(10-19 yt-dlp, 아래 1절)

## 2. 병행 시험 설계(1주)

- **기간:** 예약이 10-27 12:00까지 원음형으로 차 있다. 시험은 **10-27 18:00부터 7일(21편)** 이다.
- **배분:** 하루 3편 가운데 **08:00 원음형, 12:00 해설형, 18:00은 날마다 번갈아** 둔다. 7일이면 원음 10~11편, 해설 10~11편이 된다.
  - 시간대 효과를 지우려고 18:00을 번갈아 쓴다.
  - 관리자 안인 «해설형 하루 1~2편»과 같은 범위다.
- **비교 기준**
  - **주:** 공개 24시간 조회(유튜브). 형식별 중앙값을 비교한다.
  - **보조:** 6시간 0회 편수(가이드 위반 신호), 48시간 조회, 구독 전환(가능하면 Analytics).
- **판정(7일 뒤)**
  - 해설형 24시간 중앙이 원음형의 **2배 이상**이면 하루 3편 중 2편을 해설형으로 바꾼다.
  - **1~2배**면 1주 더 같은 배분으로 본다.
  - **1배 미만**이면 원음형으로 돌아간다.
  - 6시간 0회가 2편 이상 나온 형식은 배분과 상관없이 소재 기준부터 다시 본다.
- **고정할 것:** 같은 주에 제목 틀, 태그 수(5~9), 업로드 경로(`publish_ko.sh` 관문 전부)를 바꾸지 않는다. 형식 말고 다른 차이를 만들지 않기 위해서다.

## 3. 소재 선정 기준

| | 해설형(«~하는 이유») | 원음형(이야기 순간) |
|---|---|---|
| 무엇 | 해외의 **신기한 과정·행동·동물 습성**. 말 없이 그림만 봐도 «저걸 왜?»가 생겨야 한다 | 국내 크리에이터 롱폼의 **주고받는 순간**(상황→충돌→전환→작은 결말) |
| 답 | 끝에서 **한 문장으로 닫히는 사실**. 출처 URL로 확인 가능해야 한다 | 닫는 한 줄(반응) |
| 원본 | 개인 크리에이터의 롱폼·쇼츠 2~3곳을 엮는다. 방송사·대형 미디어(Business Insider·Smithsonian 등)는 피한다 | 1편 1크리에이터 |
| 0~2초 | 가장 신기한 **동작 중 클로즈업 + 화살표**. 고정 와이드는 쓰지 않는다(채점 카드 1번) | 클로즈업이나 인서트(카메라 문법 §3) |
| 거르는 것 | ① 원본 설명에 «무단·고소·reupload» 경고 ② frame_dup 경고(10/64 이하) ③ 국내에 같은 주제의 큰 영상이 있으면 각도를 바꾼다(크랜베리는 600만 회급 2편) | 연령 제한, 경고 채널, 가난 구경·정치·죽음·성 농담 |
| 후보 모으기 | GPT 후보 12개/회 → 유튜브에 서로 다른 촬영자 3곳 이상 있는지 확인 | GPT 순간 후보 + 전사 훑기 |

## 4. 가이드 범주 피하기(ls11 사고 반영)

- **ls11:** 제목의 위험 행위 낱말 하나로 피드 0이 됐다. 소유주 판정은 «조회 0 = 가이드 위반»이고, 이 편은 10-18에 비공개로 돌렸다.
- **소재 단계:** 7범주(위험 행위·칼·마약·총기·살인·피·어린아이 대상)에 닿는 소재는 **후보 목록에서 뺀다.** 해설형에서 특히 다음을 뺀다.
  - 동물 사냥·포식 장면(피)
  - 칼날 기계 클로즈업(칼)
  - 높은 곳·불·맹수 맨손 접촉(위험 행위)
  - 아이가 주인공인 장면
- **제목:** «행위 동사 + 위험 대상»(손 넣기·먹기 등)을 쓰지 않는다. 대상의 «정체·이유»로 묻는다. `guide_check`가 대체 제목을 낸다.
- **관문(그대로):** `guide_check`(낱말, exit 5) → `p1_check`(화면 11범주, exit 6) → 업로드 → 태그 0 예약 취소 → 공개 6시간 0회면 비공개.
- **설명란 공익 고지:** 넣지 않는다. 고지 문구가 피드를 사 주지 못한다는 실측이 있다(소형 479~655회 vs 무고지 1.4만~6.3만). 맥락은 화면과 음성 안에 담는다.
