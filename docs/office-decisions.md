# 오피스 결정 요청 규칙 (AI 오피스, 2026-10-29)

소유주에게 물을 일이 생기면 관리자에게 메시지를 보내지 말고 오피스에 올린다.
소유주는 폰 알림을 받고 버튼으로 답하고, 답은 묻는 세션 터미널에 바로 들어온다.

## 올리는 법

```
node D:/midform/office/ask.js "질문 한 문장" --lane <레인> --options "안1|안2|안3" --rec "안1" --from "<이 세션 이름>"
```

- 메인 PC 밖(노트북·미니 PC)은 `~/ai-office-agent/office/ask.js` (https://office.grow-up.kr/ask.js 에서 받는다).
- 출력 `#번호 올림` 을 확인하고, 기다리지 말고 다른 일을 계속한다.
- 답은 이 터미널에 `[오피스 결정 답] #번호 질문 → 답` 한 줄로 들어온다. 그 답대로 따르고, 따른 결과를 handoff-manager §10 에 한 줄 남긴다.
- Orca 밖 세션이면 답이 자동으로 안 들어온다. `node .../ask.js --status 번호` 로 확인한다.

## 질문 쓰는 법

- 질문은 소유주가 화면 하나로 고를 수 있게 쓴다. 한국어만, 경로·해시·도구명·일본어는 넣지 않는다.
- 선택지는 2~4개, 서로 겹치지 않게. 추천이 있으면 `--rec` 로 표시한다(선택지 중 하나와 글자가 같아야 한다).
- 한 질문에 결정 하나. 여러 개면 여러 번 올린다.
- 소유주는 «직접 쓰기»로 선택지 밖의 답을 할 수 있다. 그 답도 그대로 따른다.

## 올리지 않는 것

- 이미 밝힌 원칙으로 답이 나오는 일(묻지 말고 고친다).
- 사고 보고 — 사고는 지금처럼 관리자에게 바로 보낸다.
- 키·토큰·비밀번호 값.
