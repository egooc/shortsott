# 목표 약 10분(터진 레퍼런스 최단 11분 < 20분 → 10분). 인사·채널명·구독 요청·쟁점 번호 호명 없음. 실존 인물 얼굴 0(콜라주 실루엣).
# 역설 한 줄 = 「勝ったのに、消えた」 — 제목·썸네일·첫 문장에 같은 낱말.
# cold
2015年3月27日、東京・有明にある家具屋の本社で、株主総会が開かれました。
最大の争点は、この会社を、父と娘のどちらに任せるかでした。
結果は、娘の側が約61%の賛成を集めて勝ちました。
ところが、その会社は7年後、この世から消えてしまいます。
勝ったのに、消えた。
株主の票で勝った人が、なぜ会社ごと失うことになったのか。
今日は、大塚家具が消えた本当の理由を、お金の流れから見ていきます。
# 成功の仕組み
話は1969年、埼玉県春日部市から始まります。
大塚勝久さんが、小さな家具の店を開きました。
この店が大きくなった理由は、売り方にありました。
入口で名前と住所を書いてもらい、案内係が一人つきっきりで店の中を回るのです。
いわゆる会員制です。
冷やかしの客は入りにくい。
そのかわり、結婚や新築で家具をまとめて買う客を、しっかりつかまえることができました。
しかも当時の家具は、結婚や新築のときに、まとめて買うものでした。
タンス、食器棚、ベッド、応接セット。
一人の客に、部屋ひとつ分の家具をまとめて買ってもらえる。
だから案内係がつきっきりでも、十分に元が取れたわけです。
この仕組みで、大塚家具は大きくなっていきました。
売り上げは2001年ごろ、700億円を超えたといわれています。
# 時代のずれ
ところが、その足元で、客の暮らしが変わり始めます。
結婚しても、婚礼家具をそろえない夫婦が増えました。
新居でまとめて買うより、暮らしに合わせて少しずつ買い足す時代です。
そこへ、安くて気軽な店が伸びてきます。
北海道から全国に広がったニトリ。
そして2006年、スウェーデンのイケアが日本に再び上陸しました。
入口で名前を書かなくていい。
誰にも話しかけられず、好きなだけ見て回れる。
大塚家具が得意だった、中くらいの値段の家具を買う客も、そちらへ流れていきます。
ここには、売り方だけでなく、もうけ方の違いもありました。
ニトリは、家具を自分たちで企画し、海外の工場でつくらせて、自分の店で売ります。
つくるところから売るところまで、ほとんど自分の手の中にあるのです。
だから、安く売っても利益が残ります。
一方の大塚家具は、国内外のメーカーから家具を仕入れて売る店でした。
仕入れた値段に上乗せできる幅には、限りがあります。
同じ安さで勝負しながら利益を残すのは、仕入れて売る側には、むずかしいのです。
つきっきりの案内は、いつの間にか、気まずいものに変わっていたのです。
大塚家具の売り上げは、少しずつ下がり始めました。
# 父と娘
2009年、創業者の勝久さんは、長女の久美子さんに社長の座を譲ります。
久美子さんは銀行勤めやコンサルタントの経験がある人でした。
彼女が考えたのは、店をもっと入りやすくすることです。
会員制をゆるめ、ふらっと立ち寄れる店にする。
しかし、この会社をつくった父から見れば、それは店の命を捨てることでした。
二人の考えは、ここで正面からぶつかります。
2014年7月、取締役会は久美子さんを社長から外し、勝久さんが社長に戻りました。
ところが半年後の2015年1月、今度は久美子さんが社長に返り咲きます。
親子で社長を取り合う、まさにお家騒動です。
# 委任状争奪戦
決着の場になったのが、冒頭の株主総会でした。
社長を選ぶ取締役を決めるのは、株を持っている人たちです。
株主総会に来られない株主は、自分の票を誰かに預けることができます。
その預ける紙が、委任状です。
父と娘は、この委任状を一枚でも多く集めようと競いました。
これが、委任状争奪戦と呼ばれる戦いです。
父も娘も、自分の側に票を集めようと、株主に手紙を送り、記者会見を開きます。
テレビは連日、この親子げんかを伝えました。
ここで両方の側が、株主に向けて同じカードを切ります。
配当です。
娘の側は、一株あたり40円の配当を、80円に倍にすると打ち出しました。
父の側は、さらに上の120円を示しました。
株主から見れば、うれしい話です。
配当とは、会社がもうけの中から株主に払うお金です。
父と娘は、株主へのお金の約束でも競い合ったのです。
ただ、配当を払うお金は、会社の稼ぎか、会社の貯金から出ていきます。
そして3月27日、娘の側が勝ちました。
どちらが勝っても、会社からたくさんのお金が出ていく約束でした。
# 勝ったあと
勝った久美子さんは、思い描いた店づくりを始めます。
会員制をやめ、誰でも入れる明るい店にしました。
騒動で名前が売れたこともあり、2015年はセールに客が集まりました。
ところが、それは長続きしませんでした。
久美子さんが取り込もうとしたのは、ニトリやイケアに通う気軽な客でした。
けれども、その客たちには、わざわざ大塚家具を選ぶ理由が見つからなかったのです。
一方で、昔ながらの手厚い接客を好んでいた客にとっては、店が変わってしまいました。
父の勝久さんは会社を去り、新しく匠大塚という家具の会社を立ち上げます。
2016年には、同じ春日部に大きな本店を開きました。
一つの家具屋が、二つに割れたのです。
ただ、家具は一度買えば長く使うものです。
大塚家具の売り上げは、2015年にセールで一時的に増えたあと、2016年から2018年まで、3年続けて減りました。
# お金の流れ
ここからが、この話のいちばん大事なところです。
大塚家具は、騒動の前、かなりのお金持ちの会社でした。
手元には、現金や有価証券がたっぷりあったのです。
ところが2016年から、毎年のように大きな赤字が続きます。
赤字になっても、一株80円の配当を、しばらく払い続けました。
稼ぎが減っているのに、出ていくお金はすぐには減らない。
貯金を取り崩して、約束を守っている状態です。
赤字の穴を埋めるために、持っていた有価証券も売っていきます。
店を減らし、売り場を小さくし、人も減らしました。
それでも、売り上げの落ち込みは止まりませんでした。
配当は2017年に40円へ、2018年にはゼロになりました。
赤字に加えて、配当や自社株買いで出ていったお金が、会社の手元を細らせていったのです。
# 身売り
手元のお金が細っていくと、会社は外からお金を入れてもらうしかなくなります。
2017年には、貸し会議室の会社と手を組みました。
2019年には、中国の家具販売とつながる会社からも出資を受けます。
それでも赤字は止まりません。
そして2019年12月、家電量販店のヤマダ電機が、大塚家具の株の過半数を引き受けました。
この瞬間、大塚家具はヤマダの子会社になります。
ヤマダが欲しかったのは、家電と家具を一緒に売る店でした。
新しい家に引っ越す人に、冷蔵庫も洗濯機も、ソファもベッドも、まとめて売りたいのです。
大塚家具の名前と売り場は、そのための材料になりました。
父から会社を守ったはずの娘は、会社そのものを他人に渡すことになったのです。
2020年12月、久美子さんは社長を辞めました。
# 消滅
その後、ヤマダは大塚家具を完全に自分のものにします。
そして2022年5月、大塚家具という会社は、ヤマダに吸収されて消えました。
冒頭の株主総会から、7年後のことです。
いまも大塚家具という名前の売り場は、ヤマダの店の中に残っています。
けれども、春日部の小さな店から始まった会社は、もうありません。
# 本当の理由
では、大塚家具を消したのは、父だったのでしょうか、娘だったのでしょうか。
父の売り方は、婚礼家具をまとめて買う時代のものでした。
その時代は、親子げんかの前に、すでに終わりかけていました。
娘の売り方は、時代には合っていました。
けれども、同じ土俵には、もっと安くて強い店がすでにいたのです。
そして騒動は店のイメージを傷つけ、そのあとの赤字と配当で、会社の手元のお金は大きく減っていきました。
株主総会で勝ったのは、娘でした。
でも、本当に勝ち負けを決めたのは、店に来なくなった客だったのかもしれません。
勝ったのに、消えた。
その答えは、票の数ではなく、レジを通った客の数にありました。
