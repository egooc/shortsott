## 3. 수익화 경로 (추정 — YPP 기준은 내 지식 기준이라 바뀌었을 수 있다)

- YPP 문턱은 구독 1,000 + (롱폼 공개 시청 4,000시간/12개월 **또는** 쇼츠 1,000만 회/90일)이다.
- 쇼츠 경로: 9-30 이후 15일 만에 약 650만 회 → 90일 1,000만은 이미 넘었을 가능성이 크다.
- 롱폼 경로: 히트 1편이 9.9만 회 × 7.8분이다. 평균 시청 35%로 잡으면 약 4,500시간이라, **롱폼 히트 1편으로 4,000시간 문턱을 넘는 계산**이다.
- 수익 구조(일반론): 쇼츠는 조회당 단가가 롱폼보다 한참 낮다. 그래서 쇼츠가 구독을 모으고, 단가는 롱폼이 버는 구조가 정석이다. 이 채널도 롱폼 히트 1편의 광고 수익이 쇼츠 수백만 회와 맞먹었을 수 있다(단가 실측 없음 — 우리 채널 애널리틱스로 확인할 것).

## 4. 쇼츠 원고 틀 (상위 3편 자막 실측)

1. **0~3초: 역설을 답부터 말한다.** «門を突破しても敵が追い詰められる城があります» / «中が空っぽの竹束が鉄砲の玉を止めました». 질문형 제목 + 답 먼저 제시하는 첫 문장.
2. **구조를 순서대로 따라간다.** 공격자 시점의 카메라가 성벽 → 돌 떨어뜨리는 구멍 → 굽은 길 → 사각 광장 순으로 진행한다. 문장은 짧고 20초에 6문장 안팎이다. 실험값·명칭(武者返し·横矢掛かり·枡形)을 하나씩 넣는다.
3. **닫는 한 줄로 제목의 역설을 다시 닫는다.** «門を突破しても狙われ続ける。それが熊本城だったのです»
4. **CTA는 주제에 붙인다.** «熊本城のような城の仕掛けが好きなら高評価とチャンネル登録を»
- 길이는 80~120초다. 쇼츠 평균보다 길지만 이야기가 하나로 닫혀서 끝까지 본다.
- 소재 축은 «사람·사건»이 아니라 **«물건·구조·일상의 왜»**다(갑옷·창·성·총·음식·의례). 사건사보다 상록(evergreen)이고 소재가 무한하다.

## 5. 롱폼 원고 틀

- 「勝った家康は、なぜ秀吉に屈したのか」처럼 **결말을 먼저 걸고 «왜»로 되감는다**(채널명 그대로 «리와인드»). 장 제목도 전부 «なぜ».
- 설명란: 대하 회차 연결(«第34回のその先へ»), 장 목차, «이 동영상을 만든 방법»(실측 지도라 생성 이미지가 아니라는 점, 음력 표기, 사료가 갈리면 갈린 채로 표시), 출처 URL.
- AI 고지를 설명란 상단과 하단에 두 번 둔다. 사료 기반이라는 신뢰 장치가 «AI 양산» 인상을 상쇄한다.
