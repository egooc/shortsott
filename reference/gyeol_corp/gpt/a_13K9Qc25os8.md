| 0~30초 대사 요지 | 명절 과자 선물 세트와 국민 간식 초코파이를 떠올리게 한다. 초코파이는 지금도 팔리지만, 이를 만든 동양그룹은 사라졌다. 시멘트·증권·보험을 가진 큰 그룹이었다는 설명으로 의외성을 만든다. |
| 큰 질문이 걸리는 때 | **16~18초**에 ‘초코파이는 살아 있는데 만든 그룹은 왜 사라졌나’라는 의문이 생긴다. 제목의 두 딸 비교는 **31~46초**, 명시적 질문은 **48~50초** ‘첫째는 왜 그룹을 지키지 못했나’, **53~59초** ‘둘째는 왜 지원을 거절했나’에 걸린다. **첫 30초 안에는 두 딸 이야기가 나오지 않는다.** |
| 제목이 약속한 장면 | 결과는 **34~41초**에 먼저 알린다. 본 이야기에서 지원 거절은 **662~668초 / 전체의 64.0~64.5%**, 동양그룹의 사실상 해체는 **736초 / 71.1%**에 나온다. |
| 제목의 ‘왜’가 풀리는 때 | 지원 거절의 이유는 **673~719초 / 65.0~69.5%**에 주주 돈·배임 가능성·동반 위기로 설명한다. 두 회사의 운명을 가른 원인은 **859~934초 / 83.0~90.2%**에 돈을 버는 방식과 계열 분리로 종합한다. |
| 산정 기준 | 전체 1,035초 기준. 첫 3%인 **0~31.05초는 정점 후보에서 제외**한다. 그래프가 없으므로 아래 정점·꺼짐은 실제 관측값이 아닌 추정이다. |

| ⑥ 이 편의 ‘터지는 포인트’ — 자료에 근거한 해석 |
|---|
| 1. **익숙한 초코파이에서 낯선 그룹 붕괴로 들어간다.** 포장지 추억·해외 소비 경험 댓글이 보여주듯, 기업사를 개인의 기억과 연결한다. |
| 2. **‘큰 몫을 받은 첫째의 몰락’과 ‘둘째의 가족 지원 거절’을 겹친다.** 결과의 역전으로 궁금하게 하고, 거절의 정당성을 판단하게 한다. |
| 3. **기업의 빚을 내 이자·퇴직금·주식·잃은 원금으로 번역한다.** 동양증권 피해에 대한 분노와 지원 거절에 대한 공감이 댓글로 나타난다. 실제 재시청·이탈 효과는 그래프가 없어 확인할 수 없다. |
