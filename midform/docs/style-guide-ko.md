# 한국어 원고 스타일 가이드 (무비리캡 성공 가이드북 통합판)

사용자가 제공한 3분무비/냐옹관 스타일 통합 지침. 나레이션·자막·제목을 쓰는 모든 생성과 검수가 이 문서를 따른다.

## 우리 포맷과의 병합 규칙 (충돌 해소)

- 이 가이드는 나레이션 중심 채널용이다. 우리 포맷은 **발화(원본 대사) 중심 + 이음매 나레이션**이므로, 구조는 기존 원칙(이음매에만, 최소, 웃음 포인트 선점 금지)을 유지하고 **언어 스타일은 이 가이드를 따른다**.
- 감정 명명: 장면의 핵심 질문(예: "그가 침착했는가")은 나레이션이 판정하지 않는다. 그 외 사건 서술은 가이드의 구어체("빡쳤죠", "멘붕이 왔죠")를 허용한다.
- 고유명사: 나레이션은 사람 이름 금지 — 역할 명사만(남자, 승무원, 판사). 대사 자막의 화자 라벨도 역할 명사로 통일한다. 단, **대사 원문 안의 이름**(판사가 "버즈닉 씨"라 부르는 것)은 원문 충실 원칙에 따라 유지.

## 핵심 규칙 요약 (전문은 아래 원문)

1. 어미: ~했습니다 60~70% / ~했죠 15~30% / ~했는데 10% / ~버렸습니다 5%
2. 금지 어미: ~에요, ~거든요, ~였어요, ~어요, ~네요 남용, **시청자 직접 질문(~을까요?) 전면 금지** — 예외는 마무리 "여러분 ~" 드립뿐
3. 번역투 0%: ~에 따라/~을 통해/~에 의해/~에 대해 금지, 서구적 추상 표현은 구체적 한국어로
4. 2중 표현 금지: "말했습니다. ~라고요." → "~라고 말했습니다."
5. 연속 동작은 한 문장으로, 임팩트용 분할만 허용
6. 마무리 드립 거의 필수: "여러분 [상황 드립]?"  중간 드립 1~2개, 억지 드립보다 자연스러움
7. 노딱 회피: 자살→스스로 세상을 등졌다, 죽이다→처리하다, 마약→수상한 가루, 테러→공격 등 (전문 10장)
8. 제목: 상황 설정+극적 반전, 결말 암시하되 미공개, 감정 임팩트 단어, 한국 인터넷 어휘

## 대사 번역 지침 — 더빙체 (2026-08-09 신설)

번역투는 조사 수준(~에 따라/통해)이 아니라 **영어 구문 구조의 이식**에서 새어 나온다. 기준: "한국 더빙판 성우가 이 대사를 그대로 읽을 수 있는가."

1. **구문을 옮기지 말고 발화 의도를 옮긴다.** 영어의 명사구·관계절 구조를 한국어에 이식하지 않는다.
   - ✗ "자넨 내가 아는 걸 모르는 호사를 누리는 거야" (luxury of not knowing 직역)
   - ✓ "자넨 몰라도 되니 편한 거야"
2. **I think / I believe / You have to 패턴 금지.** 한국어 구어는 태도를 어미가 진다.
   - ✗ "저는 자격이 있다고 생각합니다" → ✓ "전 알 권리가 있습니다"
3. **호칭은 사전이 아니라 관계로.** Son/Sir/Man 직역 금지 — 화자의 위압/존중/경멸을 한국어 호칭 체계로.
   - ✗ "젊은이" (Son) → ✓ (위압이면) "애송이" / (무시면) "이봐"
4. **관용구는 등가 관용구로.** 직역해서 뜻은 통하지만 아무도 그렇게 안 말하는 표현 금지.
5. **어순 한국어화.** 영어의 후치 수식·삽입구를 그대로 콤마로 끊어 들이지 않는다 — 한국어 문장으로 재조립.
   - ✗ "그리고 내 존재가, 자네에겐 기괴하고 이해할 수 없겠지만, 사람들을 살린다고!"
   - ✓ "내 존재가 기괴해 보이겠지. 그래도 그게 사람을 살려!"
6. **캐릭터 보이스 고정.** 인물별 하대/존대·거친 정도를 첫 줄에서 정하고 끝까지 유지. 계급·나이 관계가 화면에 있으면 그걸 따른다.

검수 낭독 테스트: 각 자막을 소리 내어 읽었을 때 (a)한국 드라마에서 들어봤을 법한가 (b)원문 없이 뜻이 서는가 (c)화자의 태도가 어미에 실렸는가 — 셋 중 하나라도 아니면 다시 쓴다.
