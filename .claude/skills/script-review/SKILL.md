# 원고 검수·보정 (TTS 전, 크레딧 0원 시점)

Gemini 2.5 Pro가 쓴 원고를 사람 대신 Claude가 1차 검수한다. 파이프라인이 `paused_for_script_review`에서 멈춘 상태에서만 동작한다 — 이 시점에는 TTS 크레딧이 아직 쓰이지 않았다.

## 절차

1. **대상 찾기**: 최신 `midform/test_runs/template_runs/*/run_summary.json`에서 `status: paused_for_script_review`와 `review.pipeline_run_id`를 읽는다. 없으면 사용자에게 어느 실행인지 묻는다.
2. **자료 읽기** (전부 파이프라인 run 디렉터리 안):
   - `script_preview.md` — 사람용 요약: 대사 인용, 나레이션 예산(gap 대비 추정 발화시간)
   - `slot_fills.json` — **편집 대상**. `slot_fills[]`의 `narration`(나레이션 슬롯)과 `caption_text`(대사 자막)
   - 근거 대조용: 해당 compress run의 `transcript_timed.json` (요약의 `internal.bootstrap_source_run_id`로 찾음)
3. **검수** (아래 체크리스트). 문제가 있으면 `slot_fills.json`을 직접 수정한다.
4. **보고**: 무엇을 왜 고쳤는지 사용자에게 표로 보여준다. 원고 승인 여부는 사용자가 정한다 — 자동 재개하지 않는다.
5. **재개** (사용자 승인 후): `node scripts/midform.js review-resume <pipeline_run_id>` → 끝나면 템플릿을 `--resume draft`로 재실행해 게이트·드래프트 완료.

## 검수 체크리스트 (이 프로젝트에서 실제 사고가 났던 순서)

**날조 — 최우선.** 트랜스크립트에 없는 사실이 나레이션에 있으면 삭제/중립화한다.
- 정체 반전 단정 금지: "옆자리에 앉았던 그 사람이 판사였다" 류. 소스에 없는 반전은 반전이 아니라 거짓말.
- **눈으로만 확인 가능한 사실**(어떤 감각이 꺼졌는지, 옷차림, 화면에 누가 있는지)은 대사가 말로 명시할 때만. 근거가 창 경계에 걸린 앞 장면 꼬리 큐(0.2초 파편)면 근거가 아니다 — 실제 사고: "A little bland" 파편 하나로 "미각이 사라집니다"라고 썼는데 화면은 시각 상실이었다. 특정 불가면 중립 표현("그다음 감각이 꺼집니다").

**나레이션 형태.** 장면 사이 이음매에만, 한 문장 한 아이디어.
- 인물 소개 금지(명패·직업·배경·동기). 이름만 쓰는 건 허용, "가난한 대학생 대릴은"은 불허.
- 감정 명명·해석·판정 금지. 누가 옳은지 정리하지 않는다. 시청자 둘이 댓글에서 다투게 두는 게 목표.
- 대사가 이미 말한 것, 화면이 보여주는 것 반복 금지.
- **단 하나의 의무**: 시청자가 따라갈 수 없게 만드는 사실이 하나 있으면(전제가 대사에 안 실린 소스) 그것만은 초반에 한 줄로. 검증법: 마지막 장면부터 역산 — 그 장면이 성립하는 데 필요한 사실이 대사에도 나레이션에도 없으면 빠진 것.
- 시간 순서: 콜드오픈이 미래 장면이면 첫 나레이션이 회상임을 명시("상황은 몇 시간 전으로 돌아갑니다").

**대사 자막(caption_text) 한국어 품질.** TTS 무관이라 수정 비용 0.
- 번역투 금지: 한국어에서 뜻이 다른 용어(intervention≠중재), 비문("따님 아버님이라고요?"), 화면 없이는 안 읽히는 줄.
- 태도와 강도 보존 — 적대적·거친 대사를 순화하지 않는다.
- 말장난은 구조를 살린다(의역으로 풀면 농담이 죽는다).
- 화자 이름은 나레이션이 쓰는 이름과 일치(자막 "남자" vs 나레이션 "대릴" 불일치 금지).
- 러닝 개그는 전 반복을 보존("진정하세요"×4 → "저 진정했어요" 같은 셋업-페이오프 쌍 확인).

**길이 예산.** `script_preview.md`의 슬롯별 `estimated_speech ⚠` 표시 확인 — 예산 초과 나레이션은 줄인다. 예산은 상한이지 할당량이 아니다: 남는 건 좋은 것.

## 수정 시 주의

- `slot_fills.json`의 `slot_id`는 건드리지 않는다. `narration`/`caption_text`만 수정.
- 나레이션 수정 = 해당 문장만 TTS 재합성(문장 해시 단위 재사용). caption_text 수정 = 비용 0.
- 대사의 **원문 의미**를 바꾸지 않는다 — 한국어 표현만 다듬는다.
- 고칠 게 없으면 없다고 보고하고 그대로 재개 제안. 억지로 고치지 않는다.
